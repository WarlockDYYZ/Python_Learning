D1、搭建项目环境生成模拟数据

    1. 搭建项目骨架
        创建虚拟环境：
            # 退出当前虚拟环境
            conda deactivate
            # 创建 3.11 版本 python 环境
            conda create -n mc_oawr_activate python=3.11
            # 激活虚拟环境
            conda activate mc_oawr_activate
            # (依据情况选择，当前我的目录是需要的)进入需求所在目录
            cd ./mc_oawr
            # 安装需求
            pip install -r requirements.txt

        常用配套命令：
            查看所有环境	conda env list
            删除环境	conda remove -n mc_oawr_activate --all
            查看当前环境已安装包	conda list
