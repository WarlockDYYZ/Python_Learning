一、Seaborn 基础架构与核心概念

    1.1 Seaborn 与 Matplotlib 的关系及优势
        Seaborn 是建立在 Matplotlib 基础上的一个高级可视化库，它通过封装 Matplotlib 的一些功能，简化了绘图过程，尤其在样式和颜色搭配上提供了更多内置选项。
        与 Matplotlib 相比，Seaborn 具有以下显著优势：
            - 简洁性与美观性：Seaborn 提供了更高级的绘图接口，能够用较少的代码创建出美观且复杂的统计图表。
                    它自带了许多预设的主题和调色板，使得生成的图表具有较高的美观度和专业性，默认的绘图风格比 Matplotlib 更加现代和吸引人。
            - 统计分析集成：Seaborn 专注于统计图形的生成，其绘图函数能够自动执行必要的统计聚合和语义映射。
                    例如，当处理具有多个测量值的数据集时，Seaborn 会自动计算均值和 95% 置信区间，并绘制误差线表示估计的不确定性。
            - 数据导向的 API：Seaborn 的 API 设计理念是让用户专注于数据的语义映射而非具体的绘制细节。
                    它的函数操作于包含完整数据集的 DataFrame 和数组，内部执行必要的语义映射和统计聚合以生成信息丰富的图表。

        简单示例：
            test.py

            1. sns.set_theme()
                作用：开启 Seaborn 美观绘图风格
                    - 不加这行：图是 matplotlib 默认样式(纯白背景，加了以后背景淡灰色的，还有白色网格线条)
                    - 加了这行：背景变灰、网格好看、字体舒服
                    - 就是一键美化
            2. tips = sns.load_dataset("tips")
                作用：加载餐厅小费数据集这是 seaborn 最经典的示例数据，包含：
                    - total_bill：账单总金额
                    - tip：小费金额
                    - smoker：是否抽烟（Yes/No）
                    - sex：性别
                    - day：星期几
                    - time：午餐 / 晚餐
                    - size：人数
            3. sns.relplot(...)
                作用：画 relational plot = 关系散点图
                参数：
                    - data=tips：用 tips 这个数据
                    - x="total_bill"：X 轴 = 账单金额
                    - y="tip"：Y 轴 = 小费
                    - hue="smoker"：用颜色区分是否抽烟
                        抽烟 = 一种颜色
                        不抽烟 = 另一种颜色
                这张图想表达：账单越高，小费是不是越多？抽烟的人小费习惯不一样吗？

                补充：
                    hue = 颜色分组
                        - 给数据按类别自动分颜色
                        - 一张图里同时看两个维度的关系
                    tips 数据集里这些都可以当 hue：
                        - hue="smoker"	是否抽烟（Yes/No）
                        - hue="sex"	性别（Male/Female）
                        - hue="day"	星期几（Thu/Fri/Sat/Sun）
                        - hue="time"	午餐 / 晚餐（Lunch/Dinner）

                    不用 hue：只能看到：账单 vs 小费所有点一个颜色，看不出人群差异。
                    用了 hue：能同时看到，账单 vs 小费，不同类别之间的差异（抽烟 / 不抽烟、男 / 女等）
                    一张图 = 两张图的信息量！

                    默认情况下：颜色 100% 自动分配：
                        - Seaborn 自动识别有几组（Yes / No → 2 组）
                        - 自动从当前主题配色板里挑最协调、最好看的颜色
                        - 自动上色 + 自动生成图例
                        - 完全不用管颜色

                    自动颜色规则（超简单）
                        1. 分类数据（文字，如男 / 女、是 / 否）
                            - 用 定性色板（区别明显的颜色）
                            - 两组：蓝 + 橙
                            - 三组：蓝 + 橙 + 绿
                            - 四组：更多颜色……
                        2. 数字数据（如年龄、金额）
                            - 用 渐变色（从浅到深）

                    自己指定颜色！使用 palette 参数

                            x="total_bill",
                            y="tip",

                            palette={"Yes": "red", "No": "green"}  # 抽烟=红，不抽烟=绿
                        )

                        最常用的好看配色：
                            - palette="Set2"
                            - palette="Dark2"
                            - palette="coolwarm"
                            - palette="rainbow"
                            - palette="viridis"
            4. plt.show()
                作用：把图画出来显示在窗口不加这行，图不会弹出来。

        数据格式要求：Seaborn 主要支持两种数据格式：
            长格式（Long-form）数据：
                - 每列 = 一个变量（如：year、month、passengers）
                - 每行 = 一次观测（一个样本）
                - 每个单元格 = 一个值
                - 优点：适合复杂数据集，可显式指定变量角色
                - 示例：
                    year  month  passengers
                    1949  Jan      112
                    1949  Feb      118
                    1949  Mar      132
                长格式绘图（最常用）
                    直接把列映射到 x/y/hue 等，语义清晰：
                        sns.relplot(
                            data=flights,
                            x="year", y="passengers",
                            hue="month", kind="line"
                        )

            宽格式（Wide-form）数据：
                - 行索引 = 主体 / 维度（如：年份）
                - 每列 = 一个组别 / 指标（如：每个月）
                - 单元格 = 对应组合的数值
                - 优点：适合简单数据集，更直观
                - 示例：
                    month  Jan  Feb  Mar  ...
                    year
                    1949   112  118  132  ...
                    1950   115  126  141  ...
                flights 转宽：
                    flights_wide = flights.pivot(index="year", columns="month", values="passengers")
                    print(flights_wide.head())
                宽格式绘图（不指定 x/y）
                    Seaborn 自动把索引当 x、列当分组、值当 y：
                        sns.relplot(data=flights_wide, kind="line")

            画图优先长格式，表格查看用宽格式：
                长格式：绝大多数 Seaborn 绘图（relplot/catplot/lmplot）、需要分组 / 分面 / 多维度映射时。
                宽格式：快速画多列对比线图 / 箱线图、数据本身就是透视表结构时。

            长 → 宽（pivot）：
                wide = flights.pivot(index="year", columns="month", values="passengers")
            宽 → 长（melt）：
                long = wide.reset_index().melt(id_vars="year", var_name="month", value_name="passengers")

        1. 关于宽格式与长格式的转换逻辑
            df_long = sns.load_dataset("flights")  # 加载数据集
                - 形态特征：这是 Seaborn 最喜欢、也是最标准的“整洁数据”。
                        它的核心原则是 “每个变量是一列，每个观测值是一行”。
                - 你的数据表现：打印出的前几行会看到三列——year（年份）、month（月份）、passengers（乘客数）。
                        每一行只记录一个特定年月下的乘客数量。
                - 形状：(144, 3)。虽然看起来行数很多（144行），但这种格式非常适合让 Seaborn 通过指定 x、y、hue（颜色分组）等参数来灵活绘图。

            长 → 宽 (Pivot / 透视)(枢轴)
                df_wide = df_long.pivot(index="year", columns="month", values="passengers")
                    - 转换逻辑：这一步类似于 Excel 中的“数据透视表”。
                            将 year 固定为行索引（index），把 month 的唯一值（Jan, Feb...）展开变成新的列名（columns），
                            最后把对应的 passengers 数值填充到单元格里（values）。
                    - 数据表现：转换后，DataFrame 会变成 12 行（代表12年）和 12 列（代表12个月份）。原本的一维列表变成了二维的交叉表格。
                    - 形状：(12, 12)。这种格式非常直观，特别适合用来绘制热力图（Heatmap），因为可以直接映射矩阵的颜色深浅。

            宽 → 长 (Melt / 融解)
                df_back_long = df_wide.reset_index().melt(id_vars="year", var_name="month", value_name="passengers")
                转换逻辑：这是 pivot 的逆操作，通常被称为“融解”。
                    - 为什么要先 reset_index()？
                        因为在宽格式中，year 是索引（Index）而不是普通列。
                        melt 函数只能对普通的列进行操作，所以必须先把索引还原成普通列。
                    - id_vars="year"：告诉程序，“年份”这一列是身份标识，保持不动，不要把它融化掉。
                    - var_name 和 value_name：
                        将宽表中被折叠起来的列名（原本的月份 Jan-Dec）重新变回一列叫 month，
                        将单元格里的具体数值重新变回一列叫 passengers。
                数据表现：经过这一步，又回到了最初的 (144, 3) 结构。

    1.3 核心对象体系
        Seaborn 的核心对象体系包括三大网格对象：
            1. FacetGrid（分面网格）：用于在数据集的不同子集上绘制相同图表的多个实例，最多支持三个维度：row、col 和 hue。
            2. PairGrid（配对网格）：将数据集中的每个变量映射到网格的列和行，用于展示变量间的成对关系。
            3. JointGrid（联合网格）：用于创建包含主图和边际图的联合图表，适合展示双变量分布。


二、核心绘图功能详解

    2.1 关系类图表（Relational Plots）
        关系类图表主要用于展示变量间的关联关系，Seaborn 提供了两种基础类型：
            relational_plots.py

        散点图（scatterplot）
            1. tips = sns.load_dataset("tips") 加载数据
                加载出来的就是一个标准的 Pandas DataFrame。
                Seaborn 内置的 load_dataset() 函数，本质上就是从网络上下载对应的 CSV 文件，并自动用 Pandas 解析成 DataFrame 对象。

                Seaborn 的核心设计哲学——与 Pandas 深度集成。
                    散点图代码中，之所以能直接写 x="total_bill"、y="tip"、hue="smoker"，
                            就是因为它接收的是一个带有列名（Columns）和索引（Index）的 DataFrame。
                            Seaborn 会在后台自动根据提供的字符串列名，去 DataFrame 中提取对应的真实数据并进行可视化。
                    这种“声明式”的绘图方式，不需要手动去把数据拆分成一个个数组，极大地提升了数据分析的效率。
                            所以，你在日常使用中，完全可以像处理普通 Pandas 表格一样，先对 tips 进行筛选、清洗或计算，然后再丢给 Seaborn 画图。
            注意：
                连续运行多行绘图代码时，Matplotlib 有一个默认行为：
                        它会创建一个全局的“当前图形（Figure）”或“当前坐标轴（Axes）”，也就是我们常说的一张画布。
                    - 第一行代码 sns.scatterplot(...)：Matplotlib 发现没有画布，于是自动创建了一张，并把基础散点图画了上去。
                    - 第二、三行代码：Matplotlib 发现已经有一张画布了，它不会自动清空，而是直接把新的图层（带颜色的点、带形状的点）继续画在这张现有的画布上。
                    - 第四行代码 sns.scatterplot(... hue="size")：同样，它又把颜色渐变的散点图和对应的图例，叠到了最上面。
                因为最后的图层可能是不透明的，或者点和点之间互相穿插，视觉上可能觉得之前的图被“覆盖”了，但实际上它们都在同一个坐标系里共存。
                        而图例（Legend）也会随着每一次绘图不断累加，所以看到了所有代码产生的图例混杂在一起。

                如何每次只显示一张独立的图？
                    方法一：画完一张就显示并关闭(最简单)：
                        在每一段绘图代码的末尾加上 plt.show()：
                            plt.show() 会把当前的画布渲染出来，并且在很多编程环境（如普通的 Python 脚本或某些 IDE）中，它会释放掉当前的画布。
                            这样下一行代码运行时，就会重新创建一张全新的空白画布。
                    方法二：手动清空当前的画布：
                        每次绘图前，显式地调用 plt.clf()（清空当前图像）或 plt.cla()（清空当前坐标轴），确保是在白纸上作画。

            2. sns.scatterplot(data=None, x=None, y=None, hue=None, size=None, style=None, ...)
                sns.scatterplot 是 Seaborn 库中最核心、最强大的函数之一，专门用于可视化两个数值变量之间的关系。
                        它最大的亮点在于可以通过“语义映射”，轻松地在一张二维图表中展示多维度的数据。
                基础定位参数：
                    - data：指定数据集，通常是一个 Pandas DataFrame（比如 tips）。
                    - x, y：指定要绘制的两个数值型变量的列名。例如 x="total_bill", y="tip"。
                三大核心“语义”参数(这六个参数基本可以满足需求)：
                    - hue（色调/颜色）
                        作用：根据指定的变量，给数据点上不同的颜色。
                        表现：如果传入的是分类变量（如 smoker, sex），Seaborn 会分配几种对比鲜明的离散颜色；
                                如果传入的是数值变量（如 size, age），它会生成一个连续的颜色渐变条。
                    - size（大小）
                        作用：根据指定的变量，改变数据点的大小。
                        表现：通常用于数值变量。例如 size="total_bill"，账单金额越大的点，在图上显示的面积就越大。你可以通过 sizes=(20, 200) 这样的参数来控制点的最小和最大尺寸。
                    - style（样式/形状）
                        作用：根据指定的变量，改变数据点的形状。
                        表现：通常用于分类变量。例如 style="time"，午餐的点显示为圆圈，晚餐的点显示为三角。这非常适合黑白打印或照顾色弱人群阅读。
                常用美化与控制参数
                    - palette（调色板）：当使用了 hue 时，可以用这个参数自定义颜色方案。
                            比如 palette="coolwarm"（蓝红冷暖色）、palette="Set2" 等。
                    - alpha（透明度）：设置点的透明度，取值在 0 到 1 之间。
                            当数据点非常密集、互相遮挡严重时，设置 alpha=0.5 可以让重叠区域的颜色变深，从而看清数据的真实密度。
                    - markers（标记形状）：如果想手动指定具体的形状，可以使用该参数。
                            例如 markers=["o", "X"] 分别代表圆形和叉号。

            3. day、size、smoker中的内容，为什么都成了图例
                Seaborn 的绘图逻辑非常直观：
                    只要你把一个数据列的名字赋值给这些语义参数，Seaborn 就会自动把它当作一个需要解释的“维度”，并强制生成对应的图例。

                结合代码 hue="day", size="size", style="smoker"，可以这样理解：
                    - hue="day"：“请用不同的颜色来区分星期几”。
                        为了让看图的人知道哪种颜色代表“周六”、哪种代表“周日”，Seaborn 必须在图表旁边画出一个颜色对照表（也就是图例）。
                    - size="size"：“请用不同大小的圆点来代表用餐人数”。
                        同样，为了说明大圆点代表6人、小圆点代表2人，它必须生成一个大小对照的图例。
                    - style="smoker"：“请用不同的形状（比如圆圈和叉号）来区分是否吸烟”。
                        为了解释形状的含义，它也必须生成一个形状对照的图例。

                如果觉得图例太多太乱，或者某些信息不需要展示，可以通过以下两种方式隐藏：
                    方法一：直接取消语义映射
                        如果根本不想在图上体现这个维度，直接把对应的参数删掉或设为 None 即可。例如：hue=None。
                    方法二：保留视觉效果，但隐藏图例
                        如果想保留颜色/大小的区分效果，但不想看图例，可以在绘图函数中加入 legend=False 参数

        折线图（lineplot）
            1. sns.lineplot(data=fmri, x="timepoint", y="signal")
                核心作用：这是最纯粹的折线图。它将时间点（timepoint）作为横轴，大脑信号强度（signal）作为纵轴。
                Seaborn 的智能处理：在 fmri 数据集中，同一个时间点其实对应了多个受试者的信号值（即一对多的关系）。
                        直接绘图时，Seaborn 会在后台自动执行一个默认操作：聚合（Aggregation）。
                        它会先计算每个时间点上所有信号的平均值（mean），画出中间那条实线；
                        然后自动计算出这个平均值的 95% 置信区间（Confidence Interval），
                        并用线条周围的半透明阴影带表示出来。

            2. sns.lineplot(data=fmri, x="timepoint", y="signal", hue="event")
                参数解析：hue 参数。event 列代表了两种不同的实验事件（事件，刺激 stim 和暗示 cue）。
                视觉效果：Seaborn 会根据 event 的分类，将数据拆分成两条独立的折线，并赋予它们不同的颜色。
                        此时，图表不仅展示了信号随时间的变化，还能直观对比不同事件下大脑信号反应的差异。

            3. sns.lineplot(data=fmri, x="timepoint", y="signal", hue="region")
                参数解析：将 hue 绑定到了 region（脑区，分为额叶 frontal 和顶叶 parietal）上。
                置信区间（阴影带）：图中的半透明阴影就是 95% 置信区间。它反映了数据的波动范围和估计的可靠性。
                如果不想看到这个阴影，或者想用标准差（Standard Deviation）来代替，可以通过参数进行调整：
                    - 关闭阴影：errorbar=None 或旧版本的 ci=None。
                    - 改为标准差：errorbar=('sd', 1)。

            4. 关闭聚合和置信区间
                estimator=None：estimator 参数控制着数据的聚合方式（默认为均值 mean）。
                把它设为 None 时，就是告诉 Seaborn：“不要帮我算平均值，直接把原始数据点连起来”。
                        因为同一个时间点有多个信号值，这会导致画出来的图出现很多垂直的连线，看起来会非常杂乱。
                errorbar=None：明确指示不绘制任何误差范围（也就是去掉了默认的置信区间阴影）。

            Seaborn 折线图的强大之处：它不仅是一个简单的连线工具，更是一个自带统计引擎的可视化函数。
            在日常绘图中，如果 X 轴是时间序列，且每个时间点只有一个观测值，Seaborn 就会画出普通的折线图；
            但如果像 fmri 这样存在重复观测值，它就会自动完成“计算均值 + 展示不确定性”的复杂工作，极大地提升了数据分析的效率。

            5. 关闭聚合的一些现象
                设置 estimator=None 关闭聚合后，Seaborn 处理“同一个时间点对应多个受试者数据”的方式其实非常直白
                    ：它会把属于同一条线的所有数据点，严格按照它们在 DataFrame 中出现的先后顺序，直接用直线连接起来。

                - 连线规则：按原始顺序直接相连
                    在默认情况下（开启聚合），Seaborn 会先根据 X 轴（时间点）把数据从小到大排序，算出每个时间点的均值后再连线。
                    当设置 estimator=None 时，Seaborn 不再进行任何计算和排序，它只是单纯地遍历你的数据表：
                        读到第 1 行的数据画一个点，然后立刻拉一条线连到第 2 行的点，再连到第 3 行……以此类推。
                - 面对“一对多”时的视觉表现
                    - Seaborn 在同一个时间点上，会出现从一个受试者的数值“跳”到另一个受试者数值的轨迹。

            6. 运行时的一些隐性规则
                Seaborn 会在后台偷偷对 X 轴的数据进行自动排序
                -强制按 X 轴排序
                    设置 estimator=None 时，虽然关闭了均值聚合，但 sns.lineplot 依然保留了一个默认设定：
                            它会先按照 X 轴（timepoint）的值从小到大对数据进行排序，然后再进行连线。

            7. 一个脚本里生成多张图，并且最后能一次性看到它们各自独立的样子，最规范的做法是在每次绘图前，手动创建一个新画布 plt.figure()：
                # 绘制第一张图
                plt.figure() # 强制创建一张全新的空白画布
                sns.lineplot(data=fmri, x="timepoint", y="signal")

            8. 关于固定图例的位置
                方法一：注释的内容就是，Seaborn 画图本质上是在调用 Matplotlib。
                        可以在画出折线图后，通过 plt.legend() 配合 bbox_to_anchor 参数，精确地把图例锚定在画布之外。
                        plt.legend(bbox_to_anchor=(1.05, 1), loc='upper left')  # 将图例显示在图像外
                        plt.tight_layout()  # 调整布局，防止图例被裁切掉
                方法二：添加参数 legend=字典参数
                    如果你不想把图例移到外面，也可以直接取消它的自动寻址功能，强制把它固定在右上角、右下角等位置。
                    如：legend={'loc': 'upper right'}

        扩展：
            1. 关于被注释的 fmri_sorted = fmri.sort_values(by=["subject", "timepoint"])
                sort_values 会严格按照 by 列表中列名的先后顺序，依次进行分级（或称层级）排序。
                    - 第一优先级（主排序键）：程序会首先根据列表中的第一个列名，对全部数据进行整体排序。
                    - 第二优先级（次排序键）：只有当第一列的值完全相同时，程序才会启用第二个列名，在这些相同的记录内部进行二次排序。
                    - 后续优先级：如果有第三、第四个列名，逻辑以此类推，层层递进。
                如果你希望对不同级别的排序采用不同的方向(升、降)，可以通过 ascending 参数传入一个布尔值列表来实现。
                    # 比如：先按部门(A-Z)升序，部门相同时，按工资(高到低)降序
                    df.sort_values(by=['department', 'salary'], ascending=[True, False])

        relplot () 高级应用：relplot 是一个 figure-level 函数，结合了 FacetGrid 和轴级函数（scatterplot 或 lineplot），可以轻松创建多子图：
            sns.relplot(
               data=fmri, kind="line",
               x="timepoint", y="signal", hue="subject",
               col="region", row="event", height=3
            )
            构建了一个更复杂的“图表矩阵”：
            - 核心逻辑：同时使用了
                col="region"（按脑区分子图列）（脑区 region，分为额叶 frontal 和顶叶 parietal）
                row="event"（按实验事件分子图行）（事件 event，刺激 stim 和暗示 cue）
            - 视觉效果：假设 fmri 数据中有 2 种 region 和 2 种 event，Seaborn 就会自动生成一个 2x2 的子图网格（共4张折线图）。
                第一行的两张图展示的是第一种 event 下，不同 region 的信号变化。
                第二行的两张图展示的是第二种 event 下的情况。
            - 其他参数：
                kind="line"：指定绘制折线图。
                hue="subject"：在每一张小小的子图里，画出该条件下所有受试者（subject）的个体信号曲线。
                height=3：控制每个子图的高度为 3 英寸，防止子图太多挤在一起看不清。


    2.2 分布类图表（Distribution Plots）
        分布类图表用于展示数据的分布特征
            distribution_plots.py

        1. sns.histplot()（直方图）（图一、图二）
            sns.histplot(data=tips, x="total_bill", kde=True)
                作用：这是最经典的单变量分布可视化工具。它通过将连续的数据（比如账单总额 total_bill）切分成若干个区间（bins），
                        然后用柱子的高度来展示每个区间内数据的频数。
                特点：直观反映频率：能一眼看出数据主要集中在哪个范围，有没有多峰分布或异常值。
                kde=True 的作用：在柱状图的基础上，叠加一条平滑的核密度估计曲线（KDE）。
                        这样既能看到离散的频数分布，又能感受到连续的概率密度趋势。

        2.sns.kdeplot()（核密度估计图）（图三）
            sns.kdeplot(data=tips, x="total_bill", hue="smoker", fill=True)
                作用：它不画柱子，而是直接通过计算，绘制出一条平滑的曲线来模拟数据的概率密度函数。
                特点：平滑且连续：相比直方图受区间划分（bins）的影响，KDE 能更准确地反映数据的真实分布形态。
                fill=True 的作用：将曲线下方的区域用颜色填充起来，
                        视觉上更容易观察不同类别（如吸烟者与非吸烟者 hue="smoker"）之间的面积和重心差异。

        3. sns.displot()（全能分布图）（图四）
            sns.displot(data=tips, kind="ecdf", x="total_bill", hue="smoker")
                作用：它是 Seaborn 专门为数据分布设计的“图形级”全能接口。它本身不直接画图，而是通过 kind 参数来指挥调用底层的绘图引擎。
                特点：
                    - 一键切换图表类型：
                        kind="hist"（默认）：等同于调用 histplot，画直方图。
                        kind="kde"：等同于调用 kdeplot，画核密度图。
                        kind="ecdf"：绘制经验累积分布函数图（Empirical Cumulative Distribution Function）。
                                ECDF 图展示的是“小于等于某个数值的数据占总体的比例”，是一条单调递增的阶梯线，非常适合用来对比不同组数据的整体分布差异。
                    - 自动管理画布：正如我们之前讨论的，作为图形级函数，它每次运行都会自动创建一张全新的独立画布，非常适合用来做复杂的多图分面展示。

        4. warmplot（蜂群图）、boxplot（箱线图）、violinplot（小提琴图）
            核心参数速查表
                函数	        核心参数	作用说明
                boxplot	    whis=1.5	控制须线长度（即异常值的判定阈值）
                            order	自定义分类轴的显示顺序
                violinplot	split=True	当 hue 只有两类时，将小提琴一分为二对比
                            inner="box"	内部显示形式，可选 "quartile", "point", "stick"
                swarmplot	dodge=True	配合 hue 使用，让不同类别的点自动左右错开
                            size	控制数据点的大小
                共有：
                    x, y, hue：指定分类轴、数值轴及分组变量，支持多维度分组

        补充：
            1. 一些统计学的知识
                - 箱线图 (Boxplot)：宏观的统计摘要
                    箱线图是数据的“体检报告”。它不展示具体的每一个点，
                            而是用极简的图形概括出数据的五个关键统计量（最小值、下四分位数、中位数、上四分位数、最大值）以及异常值。
                    最佳用途：快速比较多组数据的集中趋势（中位数）、离散程度（箱子长短）和识别异常值。
                    短板：完全隐藏了数据的真实分布形状。比如两组完全不同的双峰分布数据，画出来的箱线图可能一模一样。

                - 小提琴图 (Violinplot)：展现整体密度形态
                    小提琴图是箱线图的进化版（箱线图 + 核密度估计）。它的胖瘦直接反映了数据在不同数值上的密集程度。
                    最佳用途：一眼看穿数据的分布形态。比如数据是否对称、有没有多个峰值（多峰分布往往意味着数据里藏着不同的子群体），
                            这些是箱线图绝对看不出来的。
                    短板：对样本量有要求（通常建议每组至少30个数据点），小样本下画出的平滑曲线可能会产生误导。

                - 蜂群图 (Swarmplot)：显微镜下的真实个体
                    蜂群图本质上是一个防重叠的散点图，它把每一个真实的数据点都老老实实地画在图上。
                    最佳用途：中小规模数据集（通常几百个点以内）。它能让你看到最真实的底层数据，发现局部的聚集或空隙。
                    短板：数据量一旦过大（成千上万），点会挤成一团黑块，不仅渲染慢，也失去了可视化的意义。

                想快速看统计摘要和异常值用 boxplot；
                想看数据分布的形状和密度用 violinplot；
                如果数据量不大，想看清每一个真实的个体，就用 swarmplot。
                实际使用时根据需要将它们组合起来，就是做数据探索时的利器

            2. 轴级（axes-level）和图形级（figure-level）
                可以把Figure（图形）想象成一张完整的“画纸”，而把Axes（坐标轴/子图）想象成画纸上用来画具体图表的“画框”。
                - 轴级函数 (Axes-level functions)：灵活的“画框画家”
                    常见的轴级函数有：
                        sns.scatterplot()   散点图
                        sns.lineplot()      折线图
                        sns.histplot()      直方图
                        sns.boxplot()       箱线图
                        sns.kdeplot()       核密度估计图
                    核心逻辑：它们只负责在一个特定的画框（Axes）里画图。如果不指定画框，它们就会默认去找当前画纸上最后用过的那个画框（或者直接新建一个），
                            这就是之前遇到“多张图叠在一起”的根本原因。
                    最大优势：极其灵活，可以随意组合。可以用 Matplotlib 提前规划好一张画纸上有几个画框，然后指挥不同的轴级函数去指定的位置作画。
                    如何控制：它们都有一个 ax= 参数，可以明确告诉它：“去第1行第2列的那个画框里画图”。
                    适用场景：当需要在一个窗口里拼凑多种不同类型的图表时（比如左边放直方图，右边放箱线图）。
                - 图形级函数 (Figure-level functions)：霸道的“总设计师”
                    常见的图形级函数主要有三个全能接口：
                        sns.relplot()       关系图
                        sns.catplot()       分类图
                        sns.displot()       分布图
                    以及专门的：
                        sns.jointplot()     双变量的深度剖析
                        sns.pairplot()      多变量的全景扫描
                    核心逻辑：它们非常霸道，每次调用都会直接接管并拥有整张画纸（Figure）。
                            它们根本不听现有的画框安排，而是自己重新建一张新画纸来画图。
                    最大优势：自带“分面（Faceting）”神技。
                            只需要告诉它按哪个变量拆分（col= 或 row=），它就能自动把数据拆分成多个子图，并整齐地排列在一张画纸上。
                            另外，它的图例通常会自动放在图表外部，不会遮挡数据。
                    如何控制：它们没有 ax= 参数，但可以通过 height=（单个子图高度）和 aspect=（宽高比）来控制整体大小。
                    适用场景：当需要快速查看多维数据（比如同时对比不同性别、不同时间下的数据分布），或者不想操心画框布局时。

            3. sns.jointplot() 和 sns.pairplot()
                - sns.jointplot()：双变量的深度剖析
                    深入研究某两个连续变量（比如 X 和 Y）的关系时，jointplot 是最完美的工具。它会在一张图里同时呈现三部分信息：
                        中心主图：展示 X 和 Y 的联合分布（如散点图）。
                        上方边缘图：展示 X 变量自身的单变量分布。
                        右侧边缘图：展示 Y 变量自身的单变量分布。
                    通过改变核心参数 kind ，可以一键切换中心主图的形态，以适应不同的数据特征：
                        kind 类型	    适用场景与特点
                        "scatter" (默认)	最基础的散点图 + 边缘直方图，适合一般数据量。
                        "reg"	        在散点图基础上自动拟合一条线性回归线及置信区间，方便观察线性趋势。（程序中用到的）
                        "hex"	        用六边形分箱代替散点，颜色深浅代表密度。非常适合大数据集，避免点重叠成一团黑。
                        "kde"	        绘制二维核密度等高线图，配合边缘的密度曲线，视觉上更平滑。
                        "hist"	        绘制二维直方图（矩形分箱），同样用于展示数据密度。

                - 当你拿到一个包含多个数值列的新数据集时，pairplot 能帮你瞬间建立全局认知。它会自动生成一个 N×N 的矩阵图（N为数值变量的个数）：
                    非对角线区域：展示每两个变量之间的两两关系（默认是散点图）。
                    对角线区域：展示该变量自身的分布情况（默认是直方图）。
                    核心参数
                        hue：神器参数！指定一个分类变量（如性别、物种），图表会自动按类别上色。这能让你一眼看出不同组的数据在多维空间里是否自然分离。
                        kind：控制非对角线区域的图形类型（如 "scatter", "reg" 等）。
                        diag_kind：控制对角线区域的图形类型（如 "hist", "kde"）。
                        vars：如果你的数据集有几十个特征，全画出来会密密麻麻看不清。可以用这个参数指定只画哪几个重点变量。

                总结：
                    维度	    jointplot()	                    pairplot()
                    分析目标	聚焦于两个特定变量的深度关系	        快速浏览所有数值变量的整体结构
                    输出形式	单个组合图（主图+两个边缘图）	    N×N 的矩阵网格图
                    常用场景	验证两个变量是否有相关性、线性关系	数据探索初期，寻找潜在的强相关特征或聚类模式
                    注意事项	只能处理 x 和 y 两个变量	        变量过多（如超过8-10个）会导致图片极其密集，建议先用 vars 筛选
                    刚拿到数据想“扫一眼”全貌就用 pairplot()；
                    发现某两个变量好像很有意思，想“盯着看”细节时，就换 jointplot()

            箱线图：适合快速抓重点（中位数、异常值），给领导汇报或做多组数据宏观对比时最常用。
            小提琴图：适合看形状，特别是当怀疑数据里有隐藏的“双峰”或复杂分布时。
            蜂群图：适合看细节，在数据量适中时，它能还原每一个真实的底层数据点。
            在实际分析中，最高效的做法往往是叠图法：用箱线图或小提琴图做“骨架”打底，再把蜂群图作为“血肉”覆盖在上面，这样既能看清宏观规律，又能洞察微观细节！


    2.3 分类数据图表（Categorical Plots）
        分类数据图表专门用于可视化分类变量：

        条形图与计数图
            categorical_plots.py

        1. 默认的均值条形图
            sns.barplot(data=tips, x="day", y="total_bill", hue="smoker")
                核心逻辑：barplot 并不是直接画出原始数据，而是先对数据进行聚合计算。
                        默认情况下，它会计算每个类别下数值变量的平均值（mean），然后用柱子的高度来展示这个均值。
                参数解读：
                    x="day"：横轴按“星期几”进行分类。
                    y="total_bill"：纵轴展示“账单总额”。程序会分别算出周一到周日每天的平均账单是多少。
                    hue="smoker"：引入第二个分类维度“是否吸烟”。
                            会看到每天的柱子上会并排显示两个不同颜色的子柱子，直观对比吸烟者和非吸烟者的平均消费差异。
                细节：柱子上方通常会有一小截黑色的“工”字型线条，这是默认的 95% 置信区间（误差线），用来表示均值估计的不确定性范围。

            补充：
                95% 置信区间误差线（Error Bar / Confidence Interval）
                    它不是工型，是因为 Seaborn 默认样式就是一条竖线，不是工字型。（工字型是 matplotlib 风格，seaborn 简化成竖线了）
                它表示：真实的平均值，有 95% 的概率落在这条线的范围里。
                    - 柱子高度 = 平均值
                    - 黑线长度 = 平均值的波动范围
                    - 95% 置信区间 = 统计学家最常用的 “可信度范围”
                作用 1：看数据稳不稳定
                    - 黑线短 → 数据集中、稳定、误差小
                    - 黑线长 → 数据分散、波动大、误差大
                作用 2：判断两组差异是否显著（看有没有差别）
                    这是科研 / 数据分析最常用的：
                    - 如果两个柱子的黑线不重叠 → 两组有显著差异
                    - 如果黑线重叠很多 → 两组差异不大
                ci=None 就会去掉置信区间黑线。

        2. 计数图（数个数）
            sns.countplot(data=tips, x="day", hue="smoker")
                核心逻辑：countplot 专门用来做频数统计。
                        它不需要提供 y 轴的数值列，它的任务很简单：数一数每个类别里有多少行数据，然后用柱子高度展示数量。
                参数解读：
                    x="day"：横轴依然是“星期几”。
                    没有 y 参数：因为纵轴的高度代表的是“记录条数”（比如周五一共有多少笔订单）。
                    hue="smoker"：同样按“是否吸烟”进行分组着色，让你一眼看出每天吸烟和非吸烟的顾客各有多少人。

        3. 自定义统计量（中位数）
            sns.barplot(data=tips, x="day", y="total_bill", estimator=np.median)
                核心逻辑：这里再次使用了 barplot，但通过 estimator 参数打破了默认的“求均值”规则。
                参数解读：
                    estimator=np.median：告诉 Seaborn，“不要给我算平均值，我要看中位数！”。
                            在数据存在极端异常值（比如有几笔超级大的账单）拉高了整体均值时，看中位数往往更能反映真实的普遍消费水平。
                补充技巧：如果觉得柱子上的误差线（置信区间）很碍眼，或者你只想展示纯粹的统计结果，
                        可以加上 ci=None（或较新版本中的 errorbar=None）来彻底关掉它。

            补充：
                estimator 的意思就是：你想用什么统计量来表示柱子的高度？
                    estimator=np.mean  # 平均值(默认)
                    estimator=np.median  # 中位数
                其他参数：
                    estimator=np.sum     # 总和
                    estimator=len        # 数量（计数）
                    estimator=np.max     # 最大值
                    estimator=np.min     # 最小值

        sns.barplot()：当需要比较数值大小时使用。例如：对比不同班级的平均分、不同部门的销售额、不同实验组的反应时长等。
        sns.countplot()：当需要统计样本数量时使用。例如：查看男女比例、统计各地区用户人数、分析不同好评等级的订单数量等。

        4. 点图(折线图加点再加线)
            sns.pointplot 点线图
            主打：展示分组均值趋势 + 对比差异 + 附带置信区间
            适合：看类别间变化趋势、组间差异，比条形图更适合看走势

            基础语法：
                sns.pointplot(
                    data=数据集,
                    x=分类横轴,
                    y=数值纵轴,
                    hue=二次分组列,
                    estimator=统计量,   # 默认 np.mean 均值
                    ci=95,              # 默认95%置信区间误差线
                    join=True           # 默认连线，False不连线
                )

            图形组成：
                - 实心圆点：对应分组的统计值（默认平均值）
                - 竖直误差线：95% 置信区间，代表均值波动范围
                - 同色折线：连接同组数据，直观看出变化趋势
                - hue 区分：不同颜色点 + 线，做多组横向对比

            常用参数详解:
                - estimator=np.mean 默认，点代表平均值
                - estimator=np.median 点代表中位数（抗异常值）
                - ci=95 默认 95% 置信区间
                - ci=68 68% 置信区间
                - ci=None 直接删除误差竖线
                - errwidth 误差线粗细
                - capsize 给误差线加上下短横线（变成工字型）
                - join=True 连线（默认，看趋势必备）
                - join=False 只显示点 + 误差线，不连线

            分组对比 hue:
                - 两条折线走势一致：趋势相同
                - 两点距离远 + 误差线不重叠：组间差异显著

            和 barplot 区别:
                - barplot：侧重数值大小对比，柱子直观比高低
                - pointplot：侧重连续趋势变化，折线看升降走势
                - 两者误差线含义完全一致，都是置信区间

            使用场景:
                - 对比不同时间段 / 类别数值变化趋势
                - 多分组同时对比走势差异
                - 需要直观判断数据差异是否显著（看误差线重叠）
                - 大数据量精简展示均值走势

            1. 旧版写法中的 palette=pal
                当把这个字典传给 FacetGrid 的 palette 参数时，Seaborn 会执行以下操作：
                    - 寻找分色依据：因为在创建 g 时指定了 hue="time"，Seaborn 知道要根据 time 这一列（包含 Lunch 和 Dinner）来给数据点上色。
                    - 查字典配色：它会拿着数据里的 time 值去 pal 字典里“查表”。
                        遇到 Lunch 的数据点，就自动填上海绿色。
                        遇到 Dinner 的数据点，就填上深灰色。

                如果不写 palette=pal，Seaborn 也会自动分配颜色（比如默认的蓝色和橙色），但使用自定义的 palette 有以下好处：
                    - 业务语义更强：可以用更直观的颜色表达含义（例如用绿色代表健康的午餐，灰色代表普通的晚餐）。
                    - 保持图表风格统一：在做一系列报告时，强制规定所有图中“午餐”必须是绿色，“晚餐”必须是灰色，显得非常专业。

                palette 的其他常见写法：
                    除了用字典精确指定外，palette 还可以直接传入 Seaborn 内置的主题名称，例如：
                        - palette="deep" / "muted" / "pastel"：使用预设的协调色系。
                        - palette="Set1" / "tab10"：适合分类较多的情况。
                        - palette="viridis" / "coolwarm"：适合连续数值或冷热对比的情况。
                    简单来说，palette=pal 就是告诉 Seaborn 严格按照‘颜色字典’来上色

            2. 关于旧写法中的 “搭台” 和 “唱戏” 两个步骤
                搭台子（初始化 FacetGrid）
                    当执行 g = sns.FacetGrid(tips, col="day", ...) 时，做了两件至关重要的事：
                        - 交出了数据主权：你把完整的 tips 数据集交给了 FacetGrid。此时，这个网格对象 g 的内部就已经把这份数据存好了，
                                并且根据 col="day" 把数据悄悄拆分成了周四、周五、周六、周日这四份。
                        - 画好了空白格子：Seaborn 创建好了对应数量的空白子图（Axes），搭建好了一个等待填充的画布框架。
                唱戏（使用 .map() 映射绘图）
                    接着执行 g.map(sns.barplot, "sex", "total_bill", ...) 时：
                        - .map() 的作用就是拿着之前存在 g 里面的那份数据，去遍历每一个空白的子图。
                        - 传入的 "sex" 和 "total_bill" 只是字符串形式的列名。.map() 会自动从绑定的数据中提取这两列，

                根据散点的位置，用数学方法算出一条最贴合的直线，然后画在图上。
                slope, intercept = np.polyfit(xr, yr, deg=1)
                    算直线的斜率和截距：
                        - np.polyfit：numpy 自带的拟合函数
                        - xr, yr：就是 QQ 图里的散点坐标
                        - deg=1：表示要拟合一条直线（一次方程）
                        - 计算结果：

                            intercept：截距（直线与 y 轴交点）
                    用数学公式找最贴合散点的直线参数

                line = slope * xr + intercept
                    根据参数生成直线上的所有点
                    直线公式：y = kx + b
                        - x = xr（散点的 x 坐标）
                        - k = slope
                        - b = intercept
                    算出直线上每个 x 对应的 y 值

            补充：
                xr 是 numpy 数组 (ndarray)，不是普通的 Python 列表。
                NumPy 数组支持向量化运算 + 广播机制
                    - slope 是单个数字（标量）
                    - xr 是一整组数字（数组）
                NumPy 会自动：
                    - 把标量 slope 广播成和 xr 一样长
                    - 每个元素相乘
                    - 再加上标量 intercept（再次广播）
                最终得到一个和 xr 长度完全一样的新数组 line。
                因为 xr 是 NumPy 数组，所以可以直接用数学公式批量计算趋势线上的所有 y 值。

            巩固：
                广播机制（Broadcasting）
                    定义：NumPy 在两个形状不同的数组做运算时，自动补齐维度、对齐形状，让运算合法执行，不复制多余数据，节省内存。
                    核心规则
                        - 从最后一维开始比对维度大小
                        - 维度相等 或 其中一个维度为1，就能广播
                        - 维度不足的数组，自动左侧补 1 扩充维度
                        - 维度为 1 的那一层，自动复制延展对齐另一数组长度

                向量化运算
                    定义：不用写 for/while 循环遍历每个元素，直接对整个数组整体做数学运算，底层 C 语言批量执行。
                    向量化 = 抛弃显式循环，数组整体并行计算

                关于向量
                    Python/Numpy 里的「向量化运算」里的向量，就是数学里的向量，本质是同一个东西。
                    「向量」体现在：把一组有序数值整体当成一个向量对象，不再拆成单个数字逐个算。

                    二者含义：
                        1. 狭义：一维场景 → 完全等同
                            数学一维向量 ↔ Numpy 一维数组
                            数乘、加减、线性组合规则完全一致
                            QQ 图里的 xr、yr 全是一维，100% 就是数学向量。
                        2. 广义拓展
                            数学里还有二维向量、高维向量、矩阵
                            Numpy 也对应：二维数组 (矩阵)、多维数组
                            向量化运算同样兼容，逻辑一脉相承
                        3. 微小区别
                            数学向量偏代数定义、几何意义（方向、模长、夹角等）
                            编程向量化偏执行方式：利用向量结构，批量并行计算、规避循环
                            底层数据结构与运算规则完全同源。


    3.2 PairGrid 配对网格高级应用

        PairGrid 专门用于展示变量间的成对关系，是探索性数据分析的利器：
            pair_grid.py

        基础：
            sns.PairGrid(iris)
                初始化一个绘图网格对象。
                Seaborn 会自动识别 iris（鸢尾花）数据集中的所有数值型变量（如花瓣长度、花萼宽度等），并为它们两两之间的关系预留出子图位置。
            g.map_diag(sns.histplot)
                专门设置对角线上的子图样式。
                因为对角线是同一个变量与自身的对比，所以适合用来展示该变量的单变量分布情况，这里使用了直方图（histplot）来呈现频数分布。
            g.map_offdiag(sns.scatterplot)
                专门设置非对角线上的子图样式。
                这些位置展示的是两个不同变量之间的关系，这里使用了散点图（scatterplot）来直观地观察它们是否存在相关性。

        着色：
            hue="species"
                这是 PairGrid 的核心参数之一。
                它告诉程序根据 species（物种）这一列的分类信息，用不同的颜色来区分数据点。
                这样就能一眼看出不同种类的鸢尾花在特征分布上有什么差异。
            g.map_diag(sns.kdeplot)
                这次在对角线上换成了核密度估计图（KDE）。相比直方图，KDE 能够画出更平滑的曲线，从而更优雅地展示数据的概率密度分布。
            g.add_legend()
                因为我们引入了 hue 颜色分组，必须加上这行代码来手动显示图例，否则图表中就不会标注哪种颜色代表哪个物种。

        总结：
            PairGrid 就像是一个灵活的“乐高底板”，它本身不画图，而是提供一个结构化的网格。
            需要通过 .map_diag()（画对角线）、.map_offdiag()（画非对角线）或者 .map_upper() / .map_lower()（画上/下三角）等方法，
            把具体的绘图函数（如散点图、直方图、KDE图等）填进去，从而打造出高度定制化的多维数据分析图表。

        高级配置：
            vars=["sepal_length", "sepal_width"]
                默认情况下，PairGrid 会把数据集中所有的数值型字段都拉进来两两配对。
                如果只想聚焦于某几个特定的特征（比如只看花萼的长度和宽度），就可以通过 vars 参数来指定，这样生成的网格会更简洁、更有针对性。
            hue="species"
                继续按物种分类着色，能直观看到不同种类的鸢尾花在“花萼长宽”这个二维平面上的分布差异。
            g.map(sns.scatterplot)
                因为这里只选了2个变量，网格非常简单，直接用 .map() 把所有子图统一画成散点图即可。

            PairGrid 最强大的功能之一，它把一个正方形的网格切分成了三个独立区域，允许填入完全不同的图表：
                - g.map_upper(...)：负责绘制对角线右上方的所有子图。
                    这里用了基础的散点图，展示两个变量的原始数据关系。
                - g.map_lower(...)：负责绘制对角线左下方的所有子图。
                    这里换成了核密度估计图（KDE），并且加了 fill=True 让它带有颜色填充。KDE图能很好地展示数据的密度聚集区，弥补了散点图在数据重叠时的不足。
                - g.map_diag(...)：依然是处理对角线，用直方图展示单个变量的频数分布。
                这样一来，一张图里既包含了原始数据点，又包含了平滑的密度分布，还包含了单变量的统计特征，信息量极大。

            自定义单行/单列的非对称网格
                前面的 PairGrid 画出来的都是正方形的矩阵，而这里打破了常规：
                    - y_vars=["tip"] 和 x_vars=["total_bill", "size"]
                        当分别指定 x_vars 和 y_vars 时，Seaborn 就不再画全量的配对矩阵，而是根据你的指令生成一个非对称的网格。
                        这里的意思是：Y轴固定看小费（tip），X轴分别去对比总账单（total_bill）和用餐人数（size）。
                    - 实际效果：最终会生成一个 1行2列 的图表。
                        左边是“总账单 vs 小费”的散点图，右边是“用餐人数 vs 小费”的散点图。
                        这种画法非常适合用来专门研究某一个核心指标（如 tip）与其他多个因素之间的相关性。
                    - height=4：设置每个子图的高度为4英寸，让图表整体看起来更大、更清晰。

            补充：
                关于 .map 和 .map_dataframe
                    .map 和 .map_dataframe 看起来都是把绘图函数“映射”到网格上，但它们处理数据的方式有着本质的区别。
                    .map 传递的是纯数组（底层数据），而 .map_dataframe 传递的是完整的 DataFrame（带标签的切片）。

                    - 在 Seaborn 中，.map 是 PairGrid 最基础、最常用的方法。
                        当你调用 g.map(sns.scatterplot) 时，Seaborn 会在后台自动提取当前子图对应的 X 轴和 Y 轴的纯数值数组
                        （比如 Numpy 数组或 Pandas Series），然后直接传给 sns.scatterplot。
                    - .map_dataframe 的存在，是为了解决那些必须依赖完整 DataFrame 结构才能工作的复杂绘图需求。
                        当你使用 .map_dataframe(func, x="列名A", y="列名B") 时，Seaborn 不会只提取两个孤立的数组，
                        而是会把当前子图所对应的整块数据切片（一个小型的 DataFrame）完整地传递给绘图函数 func。

                    两者的核心区别：
                        维度	        .map(func)	                            .map_dataframe(func, x="...", y="...")
                        传递的数据	纯粹的坐标数组 (Array/Series)	            带有列名的完整 DataFrame 切片
                        适用场景	    绝大多数 Seaborn/Matplotlib 原生绘图函数	需要依赖列名在函数内部进行复杂逻辑处理的自定义函数
                        通俗比喻	    像是直接把切好的菜（数组）递给厨师	        像是把装着菜的整个篮子（DataFrame）递给厨师

                    在绘制标准的散点图、直方图时，直接用 .map 是最简洁的；
                    一旦你要像写 QQ 图那样深度定制，通过列名去操作数据，.map_dataframe 就是不二之选

                扩展：
                    map_upper、map_lower 和 map_diag 在默认情况下，确实都是传递纯数值数组（Array/Series）的。
                    不过，这三者在传递数组时，有一个非常关键的区别：它们传递给绘图函数的数据量是不一样的。
                        方法	                    传递的数据量	        典型绘图函数需求
                        map_diag	            1 个数组 (单变量)	    只需要 x (如直方图、KDE图)
                        map_upper / map_lower	2 个数组 (双变量)	    需要 x 和 y (如散点图、热力图)
                        map_dataframe	        完整的 DataFrame 切片	需要在自定义函数内部通过列名找数据

                    虽然它们传递的都是数组，但很多 Seaborn 的原生绘图函数（如 sns.histplot, sns.scatterplot）其实非常“智能”。
                    它们既能接收纯数组，也能接收带有列名的 DataFrame。
                    这就引出了两种不同的调用习惯：
                        1. 隐式传递（直接喂数组）
                            g.map_diag(sns.histplot) 或 g.map_upper(sns.scatterplot) 时，
                            Seaborn 会在后台默默地把对应的数组提取出来，直接塞进绘图函数里。
                            这种写法最简洁，也是官方文档中最常见的用法。
                        2. 显式传递（指定 x 和 y）
                            如果写成 g.map_upper(sns.scatterplot, x="sepal_length", y="sepal_width")，这时候 Seaborn 就会切换模式：
                            它不再盲目地按顺序提取数组，而是会根据指定的列名，去底层的 DataFrame 里精准查找对应的两列数据，
                            然后再以数组的形式传给 scatterplot。
                    只要使用的绘图函数能够兼容接收纯数组（绝大多数 Seaborn 和 Matplotlib 函数都可以），
                    直接使用 map_diag、map_upper 和 map_lower 就是最方便的选择！

        pairplot 快捷函数：
            sns.pairplot(iris, hue="species", height=2.5)
                - height=2.5：控制图中每一个小方格（子图）的高度（单位是英寸）。
                    因为 pairplot 生成的是正方形网格，设置高度后，宽度会自动匹配。数值越大，整张图的尺寸就越大，看得越清晰。

            下面那个进阶版：
                - palette="Set2"：指定调色板。
                    当使用了 hue 进行分组后，Seaborn 需要为不同组别分配颜色。
                    "Set2" 是 Seaborn/Matplotlib 内置的一种配色方案，它能提供一组视觉上比较柔和且区分度高的颜色。
                    也可以换成 "husl", "deep", "Set1" 等其他配色主题。
                - diag_kind="kde"：专门控制对角线子图的显示方式。
                    默认情况下，对角线画的是直方图（histogram）"hist"。
                    设置为 "kde" 后，对角线会改为绘制核密度估计图（Kernel Density Estimate）。
                    KDE 是一条平滑的曲线，能比直方图更直观地展示出单个变量的概率分布形态（比如是单峰、双峰还是偏态分布）。

        补充：
            sns.pairplot() 非常智能，它会自动读取并筛选数据集中的数值列（如 int、float 类型）来进行绘图。
                具体来说，它的工作逻辑是这样的：
                    - 自动提取数值列：当把整个 DataFrame（比如 iris）传进去时，Seaborn 会自动识别出哪些是数值型特征，并将这些列作为绘图的变量。
                    - 自动忽略非数值列：对于字符串、分类对象等非数值类型的列，pairplot 默认会直接跳过，不会把它们纳入矩阵的行列中。
                    - hue 参数的特殊性：虽然 pairplot 只画数值列的关系，但像在代码中使用的 hue="species"，
                            这里的 "species" 即使是一个分类（非数值）列也没关系。因为它的作用仅仅是给数据点“上色”分组，而不是用来画坐标轴的。

            **kwargs Keyword Arguments（关键字参数）
                **kwargs 允许在调用函数时传入任意数量的、带有名字（键名）的参数。
                在函数的内部，这些参数会被自动打包成一个字典（dict），方便你灵活地提取和使用。

    3.3 JointGrid 联合网格应用
        JointGrid 用于创建包含主图和边际图的联合图表：
            joint_grid.py

        - JointGrid：创建一个 “中间 + 上下 + 右侧” 的三图组合布局
        - plot_joint：画中间的主图（散点、回归、等高线…）
        - plot_marginals：画上下 / 右侧的边际图（直方图、密度图…）

        六边形分箱热力图，适合数据量大、散点重叠严重场景，用格子颜色深浅表示数据点密集程度
        当散点图点太多、重叠看不清时，用六边形格子统计点的密度，颜色越深 = 点越多。
            解决问题：
                普通散点图：点重叠 → 黑乎乎一片；看不出哪里最密集
                hexbin 图：把坐标切成无数个小六边形；每个格子统计里面有多少个点；用颜色深浅表示数量；一眼看出数据最集中的区域

            - plt.hexbin
                替代散点图，把坐标区域划分成正六边形网格，统计每个格子内的数据数量
                    格颜色越深 = 该区间数据越集中
            - gridsize=20
                控制六边形格子数量，数值越大格子越小、划分越精细
            - cmap="Blues"
                配色映射，浅色→深色代表数据密度由低到高
            - 边际图参数
                bins=20：直方图柱子数量
                alpha=0.3：透明度，避免遮挡视觉
            看图含义
                - 中间蓝底六边形：账单和小费密集聚集区域一目了然
                - 上下黑色浅透直方图：分别展示账单、小费单独数值分布

            封装自定义函数
                原生 hexbin 不能直接传单一主题色，用 sns.light_palette()
                基于指定颜色自动生成浅→深渐变配色条，适配六边形密度图

                cmap = sns.light_palette(color, as_cmap=True)：
                    - 输入一个颜色：如 red
                    - 输出一个从浅红到深红的渐变配色板
                    - 这就是热力图的颜色渐变来源！

        补充：
            cmap = sns.light_palette(color, as_cmap=True)
                给一个颜色 → 自动生成一套「从浅到深」的渐变色板，专门给热力图、六边形图使用。
                - sns.light_palette：seaborn 提供的生成浅色渐变调色板的工具
                - color：传入的主色（比如 red、blue、green）
                - as_cmap=True：输出格式是 cmap（颜色映射表），专门给绘图函数用

                传入：color="red"(其他颜色当然也可以，如"blue"、"green"、"purple")
                sns.light_palette 会生成：浅红 → 淡红 → 正红 → 深红 → 暗红，一整套从浅到深的红色渐变！
                        并且打包成 cmap 格式，直接给 plt.hexbin 使用。
                plt.hexbin（六边形分箱图）必须要一整套渐变色，不能只给一个红色！

                as_cmap=True 是什么？
                    - palette（色板）：一组颜色列表 [浅红, 红, 深红]
                    - cmap（颜色映射）：可以连续渐变的专用颜色对象
                hexbin 必须要 cmap，不能要普通列表！所以必须加 as_cmap=True。

            关于 cmap
                - 不是字符串、不是颜色列表
                - 它是 Matplotlib 内置的「线性分段颜色映射对象」
                - 内部封装好了：
                    渐变起点色（极浅红）
                    渐变终点色（纯深红）
                    数值 → 颜色的映射规则
                    归一化配色逻辑
                不加 as_cmap=True
                    RGB 颜色列表，不能直接传给 hexbin/heatmap 当配色条使用。

                hexbin 会自动把格子内数据数量映射到 0~1
                    数量越少 → 取cmap偏浅色
                    数量越多 → 取cmap偏深色
                全程由这个 LinearSegmentedColormap 对象自动配色

            关于自动传参
                在 FacetGrid / PairGrid / JointGrid 里：
                g.map () 或 g.plot_joint () 会自动：**
                    - 自动把网格保存的 x, y 数据传给函数
                    - 自动把写在后面的参数（color, alpha 等）传给函数
                    - 只需要写函数名 + 额外参数，不用管数据！
                g 存数据 → plot_joint 自动传 x/y → 自定义函数只管画图！

        不能通过组合不同的网格对象，创建复杂的多子图布局，因为：

四、样式管理与主题定制

    4.1 主题设置与样式切换

        Seaborn 提供了五种预设主题，每种都适合不同的应用场景：

        预设主题列表：
            darkgrid（默认）：深色网格主题
            whitegrid：浅色网格主题
            dark：深色主题（无网格）
            white：浅色主题（无网格）
            ticks：带刻度的主题

            主题切换时全局设置，后面的设置会覆盖前面

        只想让某一张特定的图拥有特殊的风格，而不影响其他图表，就可以使用 with sns.axes_style("样式名"): 这种写法。
            代码中，尽管全局主题被设为了 "ticks"(最后一次主题设置)，但由于使用了 with 语句，
                    中间这张散点图会临时采用 "white"（纯白背景、无网格线）的风格进行绘制。
                    出了 with 的代码块后，后续画的图依然会恢复成 "ticks" 主题。

        补充：
            Matplotlib 的绘图机制是“延迟渲染”和“状态保留”
                连续三次切换主题，前三个 sns.scatterplot 其实都在同一张“画布”（Figure）上作画。
                当连续运行它们时，Seaborn 并没有立刻把前三张图分别弹出来，而是把它们都叠加在了当前的画布上。
                直到最后执行 plt.show() 时，程序才会把当前这张已经叠了三层内容的画布展示出来，
                所以视觉上只能看到最后一层（也就是 style="ticks" 主题下的那张散点图）。

                而第二张图片之所以能独立显示，是因为在 with sns.axes_style("white"): 之前加了 plt.figure(figsize=(6, 6))。
                这行代码相当于新建了一张全新的空白画布，所以第四张图就被画在了新画布上，最终通过 plt.show() 独立展示了出来。

                改进(实际代码中已做修改)
                如果希望每切换一次主题，就独立生成并显示一张对应的图表，只需要在每次切换主题并画图后，
                        加上一个 plt.show()，并在显示后调用 plt.close() 来清空当前的画布即可。

        注意：
            最开始设置了全局字体为 'Microsoft YaHei'（微软雅黑）。
            如果在后续的绘图中使用了 sns.set_theme()，Seaborn 有可能会重置底层的 Matplotlib 参数，导致中文再次变回方框。
            如果发现中文不显示了，只需要把字体设置的代码移到所有 sns.set_theme() 之后再执行一次即可！

        自定义样式：
            sns.set_style 的第一个参数指定基础主题（如 darkgrid），第二个参数接收一个字典（dict），用于覆盖该主题下的默认细节：
                - "axes.facecolor": ".9"：设置坐标轴区域的背景色。
                        在 Matplotlib/Seaborn 中，".9" 是一种灰度简写，代表 90% 亮度的浅灰色（0是纯黑，1是纯白）。
                - "axes.grid": True：强制开启图表内部的网格线。
                - "grid.color": "white"：将网格线的颜色设定为白色。
                - "grid.linestyle": "--"：将默认的实线网格改为虚线（--），让视觉干扰更小，看起来更精致。

            sns.set_style("ticks")：切换到一个带有四周刻度短线的简洁白底主题。
            sns.despine()：这是 Seaborn 的一个专属美化函数。
                默认情况下，Matplotlib 画出的图是一个封闭的方框（有上下左右四条边框）。
                调用 despine() 后，它会自动隐藏图表顶部（top）和右侧（right）的边框，
                让图表呈现出一种更开放、更符合现代数据可视化审美的“L”型外观。

        补充：
            虽然 Seaborn 比较智能，但在实际绘图规范中，通常建议将样式控制（如 despine()）放在具体的绘图函数（如 scatterplot()）之后执行。
            这样可以确保边框的移除操作能准确作用于刚刚画好的图上，避免在某些复杂场景下出现样式不生效的情况。
            说人话，就是先画图再调样式

            set_style 和 set_sheme 的区别
                - set_style：专注视觉外观的“美工”
                    sns.set_style() 的功能非常纯粹，它只负责控制图表的视觉框架。
                        - 核心作用：专门用来调整坐标轴的背景颜色、网格线样式、边框以及刻度线等。
                        - 可选风格：它只能切换 Seaborn 预设的 5 种基础风格（darkgrid, whitegrid, dark, white, ticks）。
                        - 局限性：它不管的图表用什么颜色（调色板），也不管字体有多大、线条有多粗。
                - set_theme：掌控一切的“总指挥”
                    sns.set_theme()（或者它的别名 sns.set()）是一个更高级、更全面的全局配置函数。
                            它不仅包含了 set_style 的所有功能，还能同时控制更多维度的参数。
                    调用一次 set_theme()，你可以同时设定以下三大核心要素：
                        - style（风格）：直接调用 set_style 的功能，设定背景和网格。
                        - palette（调色板）：设定图表的默认配色方案（比如 deep, pastel, husl 等）。
                        - context（上下文/环境）：控制图表元素的缩放比例，比如线条粗细、字体大小。
                                它提供了 paper（论文）、notebook（默认笔记本）、talk（演讲幻灯片）、poster（海报）四种模式，
                                方便适应不同的展示场景。


    4.2 颜色调色板管理

        Seaborn 提供了丰富的颜色管理功能，包括预设调色板和自定义选项：

        预设调色板类型：
            分类调色板：deep, muted, bright, pastel, dark, colorblind
            顺序调色板：适用于连续数据
            发散调色板：适用于有中心值的数据


        自定义调色板
            1. 基于颜色轮的速记语法
                - "ch:r=-.5,l=.75"：这里的 "ch" 是 Cubehelix（立方体螺旋） 系统的缩写。
                        Seaborn 允许用这种简洁的字符串语法来快速定义复杂的渐变规则。
                    - r=-.5（rotation）：控制色相在颜色轮上的旋转圈数和方向。负数代表反向旋转。
                    - l=.75（lightness）：控制整体亮度的范围。它决定了整个调色板的整体明暗基调偏向明亮（或者说限制了最暗端的下限）。
                    但在 Seaborn 提取 6 个离散颜色时，为了保证渐变的层次感，它会从该规则下的较暗端开始均匀采样。
                - 6：表示从这个连续的渐变规则中，均匀提取出 6 种离散的颜色。
                - sns.palplot()：这是一个专门用来可视化展示调色板的函数，它会把生成的颜色以色块的形式画出来，方便直观地检查配色效果。

            2. 使用 RGB 值创建完全自定义的调色板
                - 这里没有调用任何内置的渐变色系，而是直接传入了一个包含 RGB 元组的列表。
                - 每个元组 (R, G, B) 中的数值都在 0 到 1 之间（对应 0-255 的百分比）。
                        例如 (0.2, 0.4, 0.6) 是一种深蓝色，(0.9, 0.9, 0.2) 是一种亮黄色。
                - 这种方式非常适合当有明确的品牌色或特定设计需求时，进行绝对精准的色彩控制。

            3. 标准的立方体螺旋调色板
                - sns.cubehelix_palette()：这是 Seaborn 提供的专门生成立方体螺旋调色板的函数。
                        这种调色板的特点是，它在亮度上呈线性变化，同时色相也在不断旋转。
                - 核心优势：即使把图表打印成黑白稿，或者对于有色觉障碍的人群来说，这种调色板依然能保持清晰的明暗层次感，不会丢失数据信息。
                - 参数解析：
                    - light=0.8：设定调色板中最浅颜色的亮度（越接近 1 越白）。
                    - n_colors=6：同样是指定生成 6 种颜色。

            4. 为什么 1. 是绿色系 3. 是紫色系
                - "ch:r=-.5,l=.75" 中的 ch 代表 Cubehelix（立方体螺旋） 系统。
                        这是一个基于 RGB 颜色空间的算法，它不是随便挑颜色，而是按照一套严密的数学逻辑在“转圈”。
                    - 默认起点：当没有明确指定从哪个颜色开始时，Cubehelix 有一个默认的起始色调（start=0），这个起点通常落在蓝色或蓝绿色附近。
                    - 旋转规则 (r=-.5)：参数 r 控制色相在颜色轮上的旋转方向和圈数。
                            -0.5 表示反向旋转半圈。这意味着颜色会从起点的蓝绿色出发，沿着颜色轮往回走，经过青色，最终到达绿色区域。
                    实际的渐变路径是：从较暗的蓝绿色出发，随着旋转和亮度的提升，逐渐过渡到较亮的青绿色，最后落在明亮的绿色/墨绿色上。
                    因为旋转幅度只有半圈（-.5），它根本没有机会绕到颜色轮另一侧的黄色或橙色区域。
                    所以，你看到的“绿色系”，其实是算法从默认的蓝绿色起点出发，根据你的旋转指令 -0.5 自动计算并提取出的 6 种均匀分布的颜色。

                - cubehelix_palette 函数的默认参数。
                    虽然只指定了亮度（light=0.8）和颜色数量（n_colors=6），但它内部还有两个决定“色相”的关键隐藏参数：
                        - start=0（起始色调）：它决定了调色板从哪个颜色开始。
                                在 Cubehelix 系统中，数值 0、1、2、3 分别大致对应蓝、红、绿、紫的起点。默认值 0 正好就是蓝色系。
                        - rot=0.4（旋转圈数）：它决定了颜色在色谱上旋转的幅度。默认的 0.4 表示旋转不到半圈。
                    所以，当运行这行代码时，Seaborn 实际上是在执行这样一套逻辑：
                            从默认的蓝色（start=0）出发，沿着颜色轮轻微旋转（rot=0.4），同时让亮度线性增加到指定的浅色（light=0.8）。
                            蓝色稍微偏转一点，加上亮度的提升，视觉上呈现出来的就是一段非常漂亮的“深蓝 -> 浅紫”渐变。

        补充：
            ch:r=-.5 并不是指某一个孤立的“终点位置”，而是定义了从起点（0%）到这个终点（100%）的完整“旋转跨度”。
                Seaborn 在后台执行这行代码时，内心戏其实是这样的：
                    - 确定起跑线：默认从 start=0（蓝绿色）出发。
                    - 确定终点线：根据你设定的 r=-.5，决定往回退半圈，这条终点线就落在了绿色的区域。
                    - 均匀切分：既然起点和终点都定好了，它就在这条完整的渐变路径上，均匀地切出 6 份。
                            所以，第 6 个色块正好就踩在了由 r=-.5 画下的那条终点线上。
                指定起点位置："ch:start=2,r=0.5"

            "ch:r=-.5,l=.75_r"：将默认的从左到右的色块绘制顺序改反转，改为从右到左

            支持 rc 参数的函数
                在 Seaborn 中，几乎所有用于全局或局部设置主题的函数都带有 rc 参数，方便随时进行覆盖和微调：
                - sns.set_theme() / sns.set() （全局总控）
                - sns.set_style() （专门控制背景、网格等风格）

    4.4 上下文管理

        Seaborn 提供了四种预设上下文，用于控制图形元素的缩放：

        预设上下文：
            - paper：适合学术论文
            - notebook（默认）：适合 Jupyter Notebook
            - talk：适合演讲
            - poster：适合海报

        不同上下文的区别：
            Seaborn 的上下文（Context）本质上就是一套“一键缩放”功能。
                    它不改变图表的背景风格或配色，而是专门控制图表中所有元素（比如字体大小、线条粗细、标记点尺寸）的整体比例。
            Seaborn 提供了四种预设的上下文模式，按元素从小到大排列依次是：paper < notebook < talk < poster。

            上下文模式	核心特点	            最佳适用场景
            paper	    字体最小、线条最细	    学术论文、期刊插图（通常版面紧凑）
            notebook	元素适中（默认设置）	Jupyter Notebook、日常数据分析报告
            talk	    字体较大、线条较粗	    PPT 幻灯片演示、会议室投影（方便后排观众看清）
            poster	    字体最大、线条最粗	    学术海报、大型展板等需要远距离观看的场景

        除了使用这四种预设模式，你还可以像之前那样，在 notebook 的基础上进行微调。
        例如 sns.set_context("notebook", font_scale=1.5, rc={"lines.linewidth": 2.5})，
        这就相当于手动把默认的字体放大了 1.5 倍，并把线条宽度强制设为 2.5，非常适合对排版有精细要求的场合。


五、高级可视化技巧

    5.1 热力图与矩阵可视化

        热力图是 Seaborn 中最强大的高级图表：
            heat_map.py

        1. 计算相关性
            .corr() 是 Pandas 的核心方法，它会自动计算数据集中所有数值型变量两两之间的相关系数（范围在 -1 到 1 之间）。
                    加上 numeric_only=True 是一个非常严谨的好习惯，它能确保代码在遇到非数值列时不会报错，只针对数字进行计算。

        2. 参数解释
            - annot=True：默认情况下热力图只显示颜色。加上这个参数后，会直接在格子里把具体的相关系数值写出来，让数据更直观。
            - fmt=".2f"：这是配合 annot 使用的格式化字符串，意思是保留两位小数。如果不加这个，格子里可能会显示一长串数字，显得非常杂乱。
            - cmap="YlGnBu"：即 Colormap（颜色映射）。选择了 "Yellow-Green-Blue"（黄-绿-蓝）的渐变配色。
                    对于相关性矩阵，颜色的深浅直接代表了相关性的强弱。
            - linewidths 和 linecolor：这两个参数给每个小格子加上了 0.5 宽度的黑色边框。
                    在处理大量数据或格子颜色相近时，边框能让图表看起来更清晰、更有条理。
            - square=True：强制让每个单元格保持正方形，这通常会让热力图在视觉上更加规整美观。

        关于 iris_corr(我本身的判断也是对的)
            iris_corr 是一个标准的 Pandas DataFrame 类型数据。
            输入是 DataFrame：
                iris = sns.load_dataset("iris") 加载的鸢尾花数据集本身就是一个 Pandas DataFrame。
            输出也是 DataFrame：
                在 Pandas 中，对 DataFrame 调用 .corr() 方法计算相关系数矩阵后，返回的结果依然会是一个 DataFrame。
            这个 iris_corr DataFrame 的结构非常清晰：它的行名（index）和列名（columns）都是原数据集中的特征名称
                    （如 sepal_length, petal_width 等），而表格中间的每一个数值，就代表了对应两个特征之间的相关系数。

        聚类热力图
            1. to pivot
                - 加载数据：flights 数据集原本是一个“长表”格式（每一行代表某年某月的一个记录）。
                - 数据透视：sns.clustermap 需要矩阵形式的数据，所以这里使用了 Pandas 的 .pivot() 方法。
                        它将 year 设为行索引，month 设为列名，passengers（乘客数量）作为填充值。
                        最终生成的 flights_wide 就是一个标准的二维矩阵（DataFrame），这也是绘制热力图的必备前提。

            2. g = sns.clustermap(...)
                - 自动生成树状图：运行这段代码后，图表的左侧和上方多了两棵像树枝一样的结构，这叫树状图（Dendrogram）。
                - 自动重新排序：Seaborn 会根据乘客数量的相似性，自动打乱原本的年份和月份顺序，把相似的年份（比如都是旅游旺季的年份）和相似的月份聚在一起。
                - row_cluster / col_cluster：这两个参数默认都是 True。如果想保留原始的时间顺序，只观察数值分布，可以把它们设为 False。

        自定义聚类
            1. metric="euclidean"（距离度量）：定义了如何计算两行或两列数据之间的“距离”。
                欧几里得距离（Euclidean）是最常用的，可以理解为空间中的直线距离；除此之外还有余弦距离（cosine）、相关系数（correlation）等。

            2. method="ward"（聚类方法/链接方式）：定义了如何将不同的簇（群组）合并在一起。
                ward 方法的目标是让同一个簇内的数据差异最小化。其他常见的方法还有 single（单链接）、complete（全链接）、average（平均链接）等。

            3. 关于树形图
                在 clustermap（聚类热力图）中，square=True 参数会被直接忽略
                clustermap 和普通的 heatmap 结构不一样。clustermap 的上方和右侧带有树状图（Dendrogram），
                        Seaborn 必须根据数据聚类的复杂程度，动态地分配树状图和中间热力图的长宽比例。
                        如果强制把中间的格子设为正方形，会导致整个图表的布局严重错乱，所以 Seaborn 为了保证能正常画出图，就自动屏蔽了这个参数。

                树形图的作用就是把“长得像”的数据强行拉到一起。
                    - 上方的树形图（列聚类 / Col Cluster）
                        计算哪些月份的乘客数量变化趋势是相似的。
                    - 右侧的树形图（行聚类 / Row Cluster）
                        计算哪些年份的整体客流表现是相似的。

                如果没有这两个树形图，热力图只是一堆按固定顺序排列的色块，很难发现规律。加上树形图后，Seaborn 会自动帮完成以下工作：
                    - 自动分组：不需要提前指定分几类，算法会根据数据的相似度自动抱团。
                    - 视觉凸显：把相似的行列放在一起后，热力图中就会出现明显的“大色块”（比如一大片明亮的黄色区域）。
                            这些色块就是最需要关注的核心规律（例如：某几个特定年份的某几个特定月份，总是客流高峰）。
                可以把这两个树形图理解为数据的“族谱”，它们直观地告诉你哪些月份是“亲戚”，哪些年份是“兄弟”
                (数据特征高度相似)

            4. 关于一些默认值
                在 Seaborn 的 clustermap 函数中，行聚类和列聚类默认就是开启的：
                    把相似的年份和月份“抱团”排列在一起，并在图表的上方和右侧生成树状图。
                    row_cluster=True（对行进行聚类）
                    col_cluster=True（对列进行聚类）
                    值设置未 False 后，原本旁边的“亲戚族谱”（树状图）会消失，热力图的行列会严格按照数据框（DataFrame）原本的索引和列名顺序来展示。

                没有显式指定 method 和 metric 参数，Seaborn 会自动采用它们的默认值来进行聚类计算：
                    method="average"（默认的聚类方法/链接方式）
                    metric="euclidean"（默认的距离度量标准）
                    “欧氏距离”计算任意两个年份或月份之间的差异大小。可以把它理解为在多维空间中两点之间的直线距离，这是最直观的距离算法。
                    “平均链接法”在合并群组时，会综合考虑组内所有点的平均距离，从而避免了一些极端情况（比如只因为某一个点特别近就强行合并），
                            能让聚类的结果更加稳健。

            5. 关于扩展的参数
                metric（距离度量）：如何定义“差异”？
                    除了默认的 euclidean（欧氏距离），常用的还有以下几种：
                    - correlation（相关系数距离）：强烈推荐在特定场景使用！ 它不关心数据的绝对数值大小，而是关注变化趋势是否一致。
                            比如分析股票或基因数据时，只要两条曲线的涨跌节奏同步，哪怕一个数值是100，一个是10，它们也会被判定为高度相似。
                    - cosine（余弦相似度）：常用于文本分析或高维数据。它只看两个向量的方向夹角，忽略长度（即绝对数值的大小）。
                    - cityblock / manhattan（曼哈顿距离）：计算的是两点在标准坐标系上的绝对轴距总和。
                            如果数据维度非常高，或者存在较多异常值，曼哈顿距离往往比欧氏距离更稳定。

                method（聚类方法/链接策略）：如何把数据“抱团”？
                    除了默认的 average（平均链接法），常见的还有：
                    - ward（离差平方和法）：非常常用且推荐。 它的目标是让合并后的簇内方差最小化。
                            简单来说，它生成的聚类结果通常结构紧凑、大小均匀，视觉效果非常好（代码中的就是它）。
                            不过要注意，ward 方法通常必须搭配 euclidean（欧氏距离）使用。
                    - single（单链接法/最短距离法）：以两个簇中最近的两个点的距离作为合并依据。
                            这种方法容易受噪声影响，产生“链式效应”，导致拉出一条长长的细条状聚类。
                    - complete（全链接法/最长距离法）：以两个簇中最远的两个点的距离作为合并依据。
                            它倾向于生成非常紧凑、直径较小的球形簇。

                如果关注绝对数值的接近程度（比如乘客数量的绝对值差异），保持默认的 metric="euclidean" 就很好。
                如果关注相对变化的模式（比如不同年份的客流淡旺季节奏是否一样），不妨试试 metric="correlation"。
                如果觉得默认的 average 聚类出来的块太松散，可以换成 method="ward" 试试，通常能得到更规整的色块分布。


    5.2 时间序列可视化

        Seaborn 在时间序列数据可视化方面提供了强大支持：

            time_series.py

        1. tips['date'] = pd.date_range(start='2026-01-01', periods=len(tips), freq='D')
            - pd.date_range：这是 Pandas 中生成时间序列的利器。
            - start='2026-01-01'：指定起始日期。
            - periods=len(tips)：生成的日期数量等于 tips 表格原本的总行数（比如 tips 有 244 行，就生成 244 个连续的日期）。
            - freq='D'：表示按“天”（Day）作为频率递增。

        2. tips['date'] = pd.to_datetime(tips['date'])
            - pd.to_datetime：确保 'date' 这一列被 Pandas 识别为标准的“时间格式”，而不是普通的文本字符串。这是绘制时间序列图的基础保障。

        3. daily_tips = tips.groupby('date')['tip'].agg(['mean', 'count']).reset_index()
            - .groupby('date')：把数据按照刚刚伪造的每一天进行归类。
            - ['tip']：只提取“小费（tip）”这一列的数据参与计算。
            - .agg(['mean', 'count'])：对每天的小费数据进行两种聚合运算——求平均值（mean）和求订单数（count）。
            - .reset_index()：因为 groupby 默认会把 'date' 变成索引（Index），这一步把它还原成普通的一列，方便后续 Seaborn 直接调用绘图。
            结果：得到了一个新的表格 daily_tips，里面包含三列：date（日期）、mean（当天平均小费）、count（当天订单量）。

            订单数（count）:它是通过“数行数”计算出来的。
                .groupby('date')（按天分组），Pandas 会把同一天发生的所有账单记录归拢到一起。
                此时，count 的作用就是去数这一天被归拢了多少条记录。
                每一条记录就代表一笔真实的消费账单，所以总就是当天的订单数。

            如果想看总收入将 "mean" 换成 "sum" 即可

        4. 关于一些参数
            errorbar='sd'（误差带）
                核心作用：会在折线周围绘制一个半透明的阴影区域，这个区域代表数据的标准差（Standard Deviation）。
                为什么要用它：在时间序列中，如果某一天有多条数据记录（比如一天有几十笔小费），光看平均值的折线会掩盖真实的数据分布情况。
                        errorbar='sd' 能直观地反映出每天数据的离散程度（波动大小）。
                    - 阴影越宽：说明当天的数据差异很大（比如有几单给了巨额小费，也有几单没给，贫富差距大）。
                    - 阴影越窄：说明当天的数据很集中，大家都差不多。

            marker='o'（数据标记点）
                核心作用：它会在折线的每一个数据节点上画一个实心圆圈（Circle）作为标记。
                为什么要用它：
                    - 强调离散性：时间序列虽然用线连着，但本质上是一个个独立的采样点。
                            加上圆点可以提醒，这些只是特定日期的观测值，而不是连续的物理信号。
                    - 提升可读性：当折线图比较平缓，或者数据点较少时，光秃秃的折线不容易看清具体的数值落在哪里。
                            加上 marker='o' 后，每个拐点都清晰可见。
                其他，标记：
                    基础几何图形 'o'：圆圈、's'：正方形 (Square)、'D' 或 'd'：菱形 (Diamond)、'p'：五边形 (Pentagon)、
                            'H' 或 'h'：六边形 (Hexagon)、'8'：八边形
                    三角形系列 '^'：尖角朝上的三角形、'v'：尖角朝下的三角形、'<'：尖角朝左的三角形、'>'：尖角朝右的三角形
                    星号与十字 '*'：星形、'+'：加号/十字、'x'：叉号、'X'：加粗的叉号（填充样式）
                    线条型 '.'：极小的点（像素点）、','：更小的点（几乎看不见）、'_'：水平短线、'|'：垂直短线

        复杂时间序列分析
            hue="year": 按照"年份"这一列给数据分组，并用不同的颜色画出每一年的折线。

            将 长格式 转换成 宽格式

            annot=True：在热力图的每个格子里直接写上具体的数字。如果不加这个，你只能看颜色猜大概。
            fmt="d"：因为乘客人数肯定是整数，这个参数强制把格子上的数字格式化为十进制整数（decimal），避免出现难看的 .0 或小数。
            linewidths=0.5：在每个小格子之间加上宽度为 0.5 的分隔线，让整个矩阵看起来像一块块整齐的瓷砖，边界更分明。

            折线图 (lineplot + hue)：适合看趋势和走势。比如想观察每年的淡旺季曲线是不是长得一样。
            热力图 (heatmap + pivot)：适合看整体分布和极值。比如想一眼扫过去，找出哪年哪月的颜色最深（乘客最多），或者整体呈现出怎样的色块规律。

            关于图例：
                Seaborn 在 lineplot 函数中为了保持图表整洁而内置的一个“防拥挤”机制
                当的分类数据过多时，Seaborn 默认会开启一个简略模式（即内部参数 legend='brief'）。
                在这种模式下，它不会把所有年份都列出来，而是会自动抽取一部分有代表性的年份（比如每隔两年抽一个，或者只展示首尾和中间的几个），
                所以原本 12 年的数据就被简化显示成了 6 个图例。
                如果想让所有年份（1949-1960）完整地显示在图例里，只需要在绘图时加一个小参数：legend='full'。

                图例过多时要考虑显示问题


    5.3 金融数据可视化

        金融数据可视化是 Seaborn 的重要应用场景：
            stock_price_analysis.py

        都是之前学过的知识，硬看也能看懂，关键行解释一下，权当复习了：
            1. dates = pd.date_range('2023-01-01', periods=252)
                生成一段连续日期，一年股市大约 252 个交易日
                pd.date_range，生成的数据类型是datatime
                而且是 pandas 专用的 DatetimeIndex（日期时间索引），正好就是 mplfinance 要求的格式

            2. stock_data = pd.DataFrame({..., index=dates)
                画 K 线必须有这 4 列：Open、High、Low、Close 而且日期必须是 index

            3. marketcolors = mpf.make_marketcolors(
                up='red',    # 上涨 → 红色
                down='green' # 下跌 → 绿色
            )
            style = mpf.make_mpf_style(marketcolors=marketcolors)
                设置 K 线风格（红涨绿跌 = 中国股市）

            4. mpf.plot(...)
                type='candle' → K 线图
                mav=(5,20) → 5 日均线、20 日均线
                volume=True → 显示成交量柱
                index=dates → 必须是日期索引，否则报错

            5. 数据生成
                returns = np.random.normal(0, 0.01, 252)
                    - np.random.normal(均值, 标准差, 数量)
                    - 均值 0 → 涨跌概率差不多
                    - 标准差 0.01 → 每天波动大约 ±1%
                    - 252 → 生成 252 天的波动

                cumulative_returns = np.cumsum(returns)
                    - cumsum = 累加
                    - 把每天的波动累加起来，形成连续上涨 / 下跌趋势
                    - 这就是股票的连续走势，不是独立随机乱跳

                prices = base_price * np.exp(cumulative_returns)
                    - 用对数收益率公式计算股价
                    - 这是金融里标准的股价计算方式
                    - 最终 prices = 收盘价 Close
                    (我的理解是对的，下面是严谨的表述)
                        1. cumulative_returns
                            是一个 长度 252 的一维 numpy 数组
                            array([0., 0.00496714, -0.00138264, ..., 0.05xxxx])
                        2. np.exp(cumulative_returns)
                            输入数组 → 输出仍然是长度 252 的数组，对每一个元素分别计算自然指数
                            array([1.0, 1.00498..., 0.99861..., ... ])
                        3. base_price * np.exp(...)
                            - base_price = 100 是标量（单个数字）
                            - 后面是 252 个元素的数组
                            - Numpy 自动触发广播机制
                            - 把 100 乘到数组里的每一个数
                            - 最终得到 252 天的每日收盘价数组

            3 个易错点:
                1. mplfinance 必须要求：日期必须是 index（索引）, 不能是普通列
                2. 必须有 4 个列：Open, High, Low, Close
                3. 要画成交量必须：数据里有 Volume 列,   设置 volume=True
