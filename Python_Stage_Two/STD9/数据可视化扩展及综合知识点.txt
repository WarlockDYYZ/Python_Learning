数据可视化综合知识点

一、Python 数据可视化生态系统概览

    1.1 主要可视化库对比分析
        Python 拥有丰富的数据可视化生态系统，每个库都有其独特的设计理念和适用场景。
            Matplotlib：基础绘图的基石
                Matplotlib 是 Python 数据可视化的基础库。它采用面向对象的设计理念，提供了极其灵活的绘图接口，几乎可以创建任何类型的静态图表。
                Matplotlib 的最大优势在于其高度可定制性，用户可以精确控制图表的每个元素，这使得它特别适合需要出版质量图表的科研场景。
                Matplotlib 也存在一些局限性。它的 API 相对复杂，即使创建简单图表也需要编写较多代码。默认的图表样式相对传统，缺乏现代感。
                对于大规模数据集（100,000 + 数据点），Matplotlib 的渲染速度会明显下降。
            Seaborn：统计可视化的优雅解决方案
                Seaborn 构建在 Matplotlib 之上，专注于统计数据的可视化。
                它提供了更高级的接口和更美观的默认样式，特别适合探索性数据分析（EDA）。
                Seaborn 的核心优势包括：与 Pandas DataFrame 的完美集成，可以直接使用数据框的列名创建复杂统计图表；
                内置了许多统计模型的可视化功能，如回归分析、相关性热力图等；提供了丰富的调色板和主题选项，使图表更加美观专业。
                Seaborn 的学习曲线相对平缓，适合快速创建美观的统计图表。
                但它也有局限性：由于基于 Matplotlib，某些高级定制仍需使用 Matplotlib 函数；不支持交互式图表，生成的都是静态图像。
            Plotly：交互式可视化的领导者
                Plotly 是一个现代化的交互式可视化库，支持多种编程语言。
                它的最大特点是原生支持交互功能，用户可以通过鼠标进行缩放、平移、悬停查看数据点详情等操作。
                Plotly 支持 3D 图表、地图可视化和动画效果，特别适合制作仪表板和 Web 应用。
                Plotly Express 作为 Plotly 的高级接口，提供了简洁一致的 API，类似 Seaborn 但产生交互式输出。
                大多数图表只需要一次函数调用即可创建，大大简化了使用流程。
                Plotly 生成的图表可以导出为 HTML 格式，非常适合在网页中展示。
                但需要注意的是，对于超大规模数据集，Plotly 在浏览器中的渲染速度可能会受到影响。
            Bokeh：高性能 Web 可视化
                Bokeh 是一个用于创建交互式 Web 图表的 Python 库。
                它专注于高性能的 Web 可视化，特别擅长处理大型数据集（百万级数据点）。
                Bokeh 提供了丰富的图表类型和交互功能，可以创建出高度可定制的交互式图表。
                Bokeh 的独特优势在于其流式数据处理能力和对大型数据集的高效渲染。它支持 WebSocket 实时更新，可以创建真正的实时仪表板。
                Bokeh 的图表可以直接在 Web 浏览器中显示，支持与用户的深度交互。但 Bokeh 的学习曲线较陡峭，需要更多的配置工作。
            Altair：声明式统计可视化
                Altair 是一个基于 Vega-Lite 规范的声明式统计可视化库。
                它的设计理念是让用户专注于 "做什么" 而不是 "怎么做"，通过简洁的语法实现复杂的可视化。
                Altair 的核心特点包括：基于 "图形语法" 的声明式语法，代码简洁优雅；
                        内置了强大的统计变换功能，可以直接在图表规范中进行数据处理；默认样式美观现代，符合现代设计美学。
                Altair 的优势在于其语法的简洁性和统计功能的强大性。它特别适合快速探索数据和创建统计图表。
                Altair 也有一些限制：基于 JavaScript 渲染，对大数据集（超过 100,000 点）可能存在性能问题；
                某些高级定制需要深入了解 Vega-Lite 规范。

    1.2 各库适用场景与学习难度
        各库的适用场景, 实际用到了自己查嘛，Matplotlib 和 Seaborn 基本就可以处理大部分场景。
            已有的 Python 和 Matplotlib、Seaborn基础，各库的学习难度排序如下：
                - Plotly Express（容易）：API 设计简洁一致，类似 Seaborn 但支持交互
                - Altair（中等）：声明式语法需要适应，需要理解数据类型系统
                - Plotly Graph Objects（中等偏难）：功能强大但 API 复杂，需要较多学习
                - Bokeh（较难）：概念较多，需要理解模型 - 视图架构，配置相对复杂
                - Matplotlib（最难精通）：虽然基础概念容易，但高级定制需要深入学习


二、核心可视化库高级特性详解

    简单了解新的库，有个印象即可，都学完，影响后面进度。

    2.1 Plotly 深度解析
        Plotly 作为现代化的交互式可视化库，在数据探索和展示方面具有独特优势。

        Plotly Express：简洁的高级接口
        Plotly Express 是 Plotly 的高级接口，设计理念是让用户用最少的代码创建美观的交互式图表。
        它的 API 设计简洁一致，类似 Seaborn 但产生交互式输出。
        基本使用非常简单。导入 Plotly Express 后，只需一行代码就能创建基础图表：
            base_plotly.py
            直接在 Web 中展示图，很，新颖

        Plotly Express 支持多种图表类型，包括：
            - 基础图表：散点图、折线图、柱状图、饼图、面积图、气泡图
            - 统计图表：直方图、箱线图、小提琴图、分布图、误差线图
            - 科学图表：热力图、等高线图、三元图、图像显示

        交互式功能详解
            Plotly 的交互式功能是其最大亮点之一。默认情况下，所有 Plotly 图表都支持以下交互操作：
                - 鼠标操作：
                    左键拖拽：旋转 3D 图表或平移 2D 图表
                    鼠标滚轮：缩放图表
                    右键拖拽：框选放大特定区域
                - 悬停功能：鼠标悬停在数据点上时，会显示该点的详细信息
                - 工具栏功能：图表右上角的工具栏提供了丰富的交互选项：
                    放大镜：放大指定区域
                    缩小镜：缩小图表
                    重置视图：回到初始视图
                    下载：导出图表为图片或数据
                    笔刷选择：选择多个数据点
                    框选缩放：框选后放大显示

            3D 散点图展示三维空间中的数据分布：
