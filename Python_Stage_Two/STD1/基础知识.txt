Python 模块与自定义包

1.1 基础概念与包结构设计
    模块: 是一个包含 Python 定义和语句的.py文件，用于封装相关功能
    包: 是一个包含__init__.py文件的文件夹，用于组织多个相关模块，形成层级结构
    模块是单个文件，包是包含模块的目录结构，而库是更广泛的概念，可以包含一个或多个包和模块

    对于数据分析项目，推荐采用现代的Src Layout 布局，这是发布到 PyPI 的最佳实践(具体格式查到的资料里面有，实际用到的时候自己再去看)
    包结构设计中，__init__.py文件是包的标识，可在该文件中定义包的初始化逻辑，如__all__、导入子模块等，__all__变量用于明确导出接口，避免在__init__.py中执行复杂操作，并提供包级文档字符串

1.2 导入机制与最佳实践
    Python 的导入机制分为绝对导入和相对导入两种方式。绝对导入以根包名为起点，完整写出模块的层级路径，适用于跨包导入场景。相对导入以当前模块的包层级为起点，通过.表示层级关系，适用于包内部的模块互导
    在数据分析项目中，推荐遵循以下最佳实践：
        - 遵循 "扁平优于嵌套" 原则，避免过度复杂的目录结构，优先选择单层或双层设计
        - 模块化设计：每个模块应承担单一职责，通过清晰的接口与其他模块交互，降低耦合度，便于测试和扩展
        - 遵循 PEP8 规范：使用描述性变量名，添加必要的注释和文档字符串，保持代码结构清晰

1.3 数据分析模块封装实战
    以一个数据分析项目为例，我们可以将不同的分析步骤封装成独立的模块：
        数据预处理模块（preprocessing.py）
        特征工程模块（feature_engineering.py）

补充知识：Z-score 标准分数 (其实数据清洗的时候用过了)
    作用：判断单个数据，偏离平均值有多远，用来识别异常值 / 离群点
    z = （当前数据 - 平均值） / 标准差
    示例调用：
        from scipy.stats import zscore
        z_scores = zscore(self.df[column])
        1.取出指定数值列
        2.计算整列：平均值μ
        3.计算整列：标准差σ
        4.每一行单独套公式
        5.输出同长度的 Series（每个值对应一个 z 分数）

        正态分布中：
            ∣z∣<1：覆盖 68% 数据
            ∣z∣<2：覆盖 95% 数据
            ∣z∣<3：覆盖 99.7% 数据
        preprocessing.py中为更严谨可修改为：
            self.df = self.df[(z_scores.abs() < threshold)]
        用绝对值，正负极端异常值一起过滤

1.4 使用 setuptools 进行打包
    现代 Python 项目推荐使用pyproject.toml进行配置，而非传统的 setup.py。基本配置自己搜
    使用在python -m build命令可以生成发行包，会在 dist 目录下生成.tar.gz（源码包）和.whl（二进制轮子）文件

    注意：
        要进入项目根目录（pyproject.toml 所在文件夹），运行：
            python -m build
        toml 格式非常严格，不允许中文、不允许格式错误(中文注释、中文符号、BOM 头、多余空格，都可能导致报错)
            文件里不能有任何中文！（包括注释、文字、标点）
            不能有多余空格、空行、奇怪字符
            必须是 UTF-8 编码

1.5 发布到 PyPI
    发布 Python 包到 PyPI 需要以下步骤：
        1. 注册 PyPI 账号并创建 API Token
        2. 配置 twine：twine config
        3. 构建发行包：python -m build
        4. 上传到 PyPI：twine upload dist/*(33)

    推荐使用 API Token 而非密码进行认证，更加安全。可以使用 Poetry 等工具简化发布流程，支持一键构建和发布
