Python 模块与自定义包

1.1 基础概念与包结构设计
    模块: 是一个包含 Python 定义和语句的.py文件，用于封装相关功能
    包: 是一个包含__init__.py文件的文件夹，用于组织多个相关模块，形成层级结构
    模块是单个文件，包是包含模块的目录结构，而库是更广泛的概念，可以包含一个或多个包和模块

    对于数据分析项目，推荐采用现代的Src Layout 布局，这是发布到 PyPI 的最佳实践(具体格式查到的资料里面有，实际用到的时候自己再去看)
    包结构设计中，__init__.py文件是包的标识，可在该文件中定义包的初始化逻辑，如__all__、导入子模块等，__all__变量用于明确导出接口，避免在__init__.py中执行复杂操作，并提供包级文档字符串

1.2 导入机制与最佳实践
    Python 的导入机制分为绝对导入和相对导入两种方式。绝对导入以根包名为起点，完整写出模块的层级路径，适用于跨包导入场景。相对导入以当前模块的包层级为起点，通过.表示层级关系，适用于包内部的模块互导
    在数据分析项目中，推荐遵循以下最佳实践：
        - 遵循 "扁平优于嵌套" 原则，避免过度复杂的目录结构，优先选择单层或双层设计
        - 模块化设计：每个模块应承担单一职责，通过清晰的接口与其他模块交互，降低耦合度，便于测试和扩展
        - 遵循 PEP8 规范：使用描述性变量名，添加必要的注释和文档字符串，保持代码结构清晰

    以一个数据分析项目为例，我们可以将不同的分析步骤封装成独立的模块：
        数据预处理模块（preprocessing.py）
        特征工程模块（feature_engineering.py）

补充知识：Z-score 标准分数 (其实数据清洗的时候用过了)
    作用：判断单个数据，偏离平均值有多远，用来识别异常值 / 离群点
    z = （当前数据 - 平均值） / 标准差
    示例调用：
        from scipy.stats import zscore
        z_scores = zscore(self.df[column])
        1.取出指定数值列
        2.计算整列：平均值μ
        3.计算整列：标准差σ
        4.每一行单独套公式
        5.输出同长度的 Series（每个值对应一个 z 分数）

        正态分布中：
            ∣z∣<1：覆盖 68% 数据
            ∣z∣<2：覆盖 95% 数据
            ∣z∣<3：覆盖 99.7% 数据
        preprocessing.py中为更严谨可修改为：
            self.df = self.df[(z_scores.abs() < threshold)]
        用绝对值，正负极端异常值一起过滤

1.4 使用 setuptools 进行打包
    现代 Python 项目推荐使用pyproject.toml进行配置，而非传统的 setup.py。基本配置自己搜
    使用在python -m build命令可以生成发行包，会在 dist 目录下生成.tar.gz（源码包）和.whl（二进制轮子）文件

    注意：
        要进入项目根目录（pyproject.toml 所在文件夹），运行：
            python -m build
        toml 格式非常严格，不允许中文、不允许格式错误(中文注释、中文符号、BOM 头、多余空格，都可能导致报错)
            文件里不能有任何中文！（包括注释、文字、标点）
            不能有多余空格、空行、奇怪字符
            必须是 UTF-8 编码

1.5 发布到 PyPI
    发布 Python 包到 PyPI 需要以下步骤：
        1. 注册 PyPI 账号并创建 API Token
        2. 配置 twine：twine config
        3. 构建发行包：python -m build
        4. 上传到 PyPI：twine upload dist/*(33)

    推荐使用 API Token 而非密码进行认证，更加安全。可以使用 Poetry 等工具简化发布流程，支持一键构建和发布


2.1 虚拟环境基础概念
    虚拟环境是一个独立的 Python 环境，它允许你在同一个系统上为不同的项目安装不同的包和版本，而不会相互干扰。
    每个虚拟环境都有自己的 Python 解释器、标准库和第三方库目录。虚拟环境的重要性体现在三个方面：
        依赖隔离：确保不同项目间的第三方库不会相互干扰
        项目可移植性：使环境配置能跨机器无缝迁移
        协作稳定性：避免 “在我机器上能运行” 的经典问题

    Python 3.3 及以上版本自带了venv模块，可以用来创建虚拟环境。创建虚拟环境的命令是：
        python -m venv myenv

    激活虚拟环境的方式因平台而异
        Windows (PowerShell)：.\myenv\Scripts\activate.ps1

2.2 虚拟环境管理最佳实践
    推荐将虚拟环境目录置于项目根目录下（如project/.venv），而非全局集中存储。创建时通过--prompt参数设置环境前缀便于识别：
        python -m venv --prompt PROJECT\_NAME --copies .venv
    其中，--copies参数确保复制基础解释器而非使用符号链接，规避解释器升级导致的环境损坏
    特别需避免--system-site-packages参数，该选项会引入全局包污染环境，破坏隔离性。

    依赖管理的核心是使用requirements.txt文件。生成依赖文件的命令是：
        pip freeze > requirements.txt
    在新环境中安装依赖：
        pip install -r requirements.txt
    为了获得更好的依赖管理体验，推荐使用pip-tools生成锁定文件：
        pip-compile requirements.in > requirements.lock

    注意：pip-compile 是 Python 第三方工具包 pip-tools 里的一个命令。
        当安装 pip-tools 后，它的可执行文件（pip-compile.exe）会被放在 Python 安装目录下的 Scripts 文件夹里。
        如果这个文件夹没有被添加到系统的环境变量 Path 中，PowerShell 就无法直接识别并运行 pip-compile。
        你可以通过以下两种方法来解决：
            方法一：使用 python -m 直接调用（最推荐，无需配置）
            这是最简单、最稳妥的方法，可以完全绕过环境变量的问题。你只需要在命令前面加上 python -m，让 Python 解释器去调用这个模块即可。
            将你的命令修改为：
                python -m piptools compile requirements.in > requirements.lock
                注：pip-compile 对应的模块名是 piptools

            方法二：配置系统环境变量（一劳永逸）
            如果你希望以后能直接在终端里敲 pip-compile 就能运行，需要把 Python 的 Scripts 目录添加到系统的 Path 环境变量中。
            1. 找到 Scripts 文件夹的路径
            可以先在 PowerShell 中输入以下命令，查看 Python 的安装位置：

                python -c "import sys; print(sys.executable)"

            假设输出结果是 C:\Users\你的用户名\AppData\Local\Programs\Python\Python313\python.exe，那么你需要找的路径就是
            把末尾的 \python.exe 替换成 \Scripts，即：
            C:\Users\你的用户名\AppData\Local\Programs\Python\Python313\Scripts
            2. 添加到环境变量
            按键盘 Win + S 键，搜索 “编辑系统环境变量” 并打开。
            点击右下角的 “环境变量” 按钮。
            在“系统变量”或“用户变量”中找到名为 Path 的变量，双击它。
            点击 “新建”，将上面找到的 Scripts 文件夹路径粘贴进去，然后一路点击“确定”保存。
            3. 重启终端
            配置完成后，必须关闭并重新打开你的 PowerShell 窗口，新的环境变量才会生效。此时再输入 pip-compile 就可以正常识别了。

        如果在使用上述方法时提示找不到 piptools 模块，说明你还没有安装 pip-tools 工具包。你可以先用以下命令安装它：
            python -m pip install pip-tools

    Python 生态中有多种依赖管理工具，各有特点：

    对于一个数据分析项目，推荐的环境配置流程如下：
    步骤 1：创建虚拟环境

        poetry install  # 安装所有依赖

三、封装小工具
3.1 命令行工具开发基础
    Python 提供了多种命令行工具开发框架，其中argparse是标准库中的基础工具，无需额外安装。
    使用 argparse 的基本流程是：创建解析器→添加参数→解析参数→执行逻辑。
    一个简单的数据分析工具示例：data_analysis_tool.py
        把你的 Python 程序，变成一个【能在终端用命令运行的工具】就像 pip、git 一样，直接输命令 + 参数就能用
    知识补充：
    1.入口
        if __name__ == '__main__':
            main()
            这是 Python 程序的入口
            当直接运行这个文件时，才会执行 main()
            被别人导入时不运行（安全规范）
    2.核心
        parser = argparse.ArgumentParser(description='Data analysis tool')
            创建一个命令行解析器
            作用：接收在终端输入的命令和参数
    3.输入
        ① 必须传的参数：输入文件
            parser.add_argument('input_file', help='Input CSV file')
            必须传 比如：data.csv
        ② 可选参数：输出文件（-o /--output）
            parser.add_argument('-o', '--output', help='Output file path')
            可写可不写，短写法 -o，长写法 --output
        ③ 分析类型（固定 3 种选择）
            parser.add_argument('--analysis-type',
                choices=['summary', 'plot', 'stats'],
                default='summary'
            )
            只能选 3 个：
            summary 数据概要（默认）
            plot 画图
            stats 统计指标
        ④ 日期列（画图时用）
            parser.add_argument('--date-column', help='Name of date column')
    4. 接收参数
        args = parser.parse_args()
        把终端输入的所有参数，放进 args 里，后面直接用。
    5. 业务逻辑：根据参数做不同事情
        df = pd.read_csv(args.input_file)
        读取输入的 CSV 文件
        ① 分析类型 = summary
            print(df.describe())
            输出数据的统计概要（均值、最大最小、数量等）
        ② 分析类型 = plot
            plt.plot(df[args.date_column], df['value'])
            plt.savefig(args.output)
            用日期列画折线图，保存成图片
        ③ 分析类型 = stats
            print(f"Mean: {df['value'].mean()}")
            print(f"Median: {df['value'].median()}")
            print(f"Standard deviation: {df['value'].std()}")
            输出均值、中位数、标准差
            超级重点：怎么在终端运行？（一看就会）

    调用：
        运行 1：输出数据概要（默认）
            python 文件名.py data.csv
        运行 2：画图
            python 文件名.py data.csv --analysis-type plot --date-column date -o figure.png
        运行 3：统计指标
            python 文件名.py data.csv --analysis-type stats

    打包好，别人就能直接：
        my_tool data.csv --analysis-type plot -o out.png

    补充：
        help之类的参数是 argparse 命令行工具 的说明文字 + 规则限制，不是代码逻辑，只是给用户看的提示 + 规则！
        1. description='Data analysis tool'
            作用：给整个工具写一段介绍（标题 / 简介），查看方法
                python 工具.py -h
        2. help='Input CSV file'
            作用：告诉用户这个参数是干嘛的（给用户看的提示文字）
                parser.add_argument('input_file', help='Input CSV file')
            用 -h 查看帮助时，会看到：
                input_file    Input CSV file
        3. choices=['summary', 'plot', 'stats']
            作用：限定用户只能从这三个里面选（只能三选一，不能乱写）


3.2 使用 Click 构建专业 CLI
    对于复杂的命令行工具，推荐使用Click库。它使用装饰器方式简化了命令行参数定义，支持子命令、参数校验、颜色输出等高级功能。
        使用 Click 重写数据分析工具：click_tool

        做了一个命令行工具箱
        可以在终端直接运行：
            python 脚本.py --help → 查看帮助
            python 脚本.py summary --help → 查看 summary 命令帮助

            python 脚本.py summary data.csv → 输出数据统计
            python 脚本.py summary data.csv -o out.txt -> 输出到文件
            python 脚本.py plot data.csv --x date --y value -o out.png → 画图

        1. 导入工具
            import click
            click：专门用来快速写命令行工具的库
        2. 创建工具箱入口
            @click.group()
            def cli():
                """Data analysis command line tool"""
                pass
            @click.group()：创建一个命令组
            作用：可以放多个子命令（summary、plot...）
            下面的 cli() 就是工具箱名字
        3. 第一个命令：summary（统计）
            - 读取 CSV
            - 生成统计信息 df.describe()
            - 如果给了 -o → 保存到文件
            - 没给 → 直接打印在终端
        4. 第二个命令：plot（画图）
            - 读取 CSV
            - 指定 --x 和 --y 列
            - 画图并保存到 --output

        Click 核心语法
        写法	                意思
        @click.group()	    创建命令工具箱
        @cli.command()	    创建一个子命令
        @click.argument()	必须传的参数
        @click.option()	    可选参数（-o /--output）
        click.echo()	    终端打印


3.3 数据分析小工具实战案例
    案例：数据清洗工具 data_cleaning_and_preprocessing.py

    这是一个终端数据清洗工具，有 2 个功能：
        1. clean → 清洗数据（删缺失值、填充值、转日期）
        2. detect_outliers → 检测异常值（Z-score）
        算 Z 分数 → 挑出超过阈值的异常 → 打印数量和内容
    用户在终端输命令就能用：
        python 文件名.py clean data.csv --convert-date date
        python 文件名.py detect_outliers data.csv --column price

    补充：
        multiple=True：同一个参数可以传多次
        nargs=2：一个参数后面必须跟 2 个值

        dropna()：删除 有空值（NaN） 的行
        subset=list(dropna)：只检查这些列有没有空值
            比如用户传了 --dropna age --dropna name
            → 只删除 age 或 name 列为空的行

        fillna 是这种格式：
            (("age", 0), ("score", 50), ("name", "未知"))


3.4 构建数据分析流水线工具
    更复杂的数据分析工具可以构建成流水线形式，包含数据读取、清洗、分析、可视化等步骤：
    complete_data_analysis_pipeline.py
    自动批量处理多个数据文件，依次执行：清洗 → 分析 → 画图
    自己不干活，只负责调度其他脚本按顺序跑！

    调用：
    python tool.py process a.csv b.csv -o result
        工具会自动执行：
            clean a.csv → result/cleaned_a.csv
            analyze cleaned_a.csv → result/analysis_a.csv
            visualize analysis_a.csv → result/plot_a.png
        然后对 b.csv 做同样操作！

    python 工具.py report 数据.csv --output report.txt
        输入一份数据 → 自动算统计指标 → 输出一份干净的文本报告

    补充：
        subprocess.run(...)
        subprocess.run([
            'python', '脚本.py', '参数1', '参数2'
        ])
        就等于在终端手动输入：
            python 脚本.py 参数1 参数2

        @data_pipeline.command()
        把函数，变成一个【终端命令】
        1. 定义了一个命令组（工具箱），名字叫 data_pipeline
        @click.group()
        def data_pipeline():
            pass
        2. 把 process 这个函数，注册成 data_pipeline 工具箱里的一个【子命令】
        @data_pipeline.command()  # <-- 就是这行！
        def process(...):
            ...
        最终在终端里就可以这样用：
            python 文件名.py process
        python 文件名.py → 运行工具箱（data_pipeline）
        process → 运行定义的子命令（process 函数）

        代码	                                终端命令
        @click.group() → data_pipeline	    python tool.py
        @data_pipeline.command() → process	python tool.py process
        @data_pipeline.command() → report	python tool.py report
