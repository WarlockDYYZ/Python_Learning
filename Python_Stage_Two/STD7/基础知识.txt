一、Matplotlib 基础概念与环境配置


    1.1 Matplotlib 简介与架构
        Matplotlib 是 Python 中最强大的 2D 绘图库，能够创建静态、动态和交互式可视化图表。
        它的设计理念是 “使简单的事情变得简单，困难的事情变得可能”，让你只需几行代码就能创建出版质量的图表。

        Matplotlib 采用三层架构设计，理解这个架构对掌握 Matplotlib 至关重要：
            Figure（画布）
                - 整个图表的容器，相当于一张白纸
                - 可以包含一个或多个 Axes
                - 负责管理所有子元素
            Axes（坐标系 / 子图）
                - 真正绘制数据的区域
                - 包含坐标轴、标题、图例等元素
                - 一个 Figure 可以包含多个 Axes，但一个 Axes 只能属于一个 Figure
            Axis（坐标轴）
                - 控制数据范围的显示（X 轴和 Y 轴）
                - 包含刻度和刻度标签
                - 负责数据到视觉空间的映射
            Artist（图形元素）
                - Figure 上所有可见的元素都是 Artist
                - 包括线条、文本、标记、图像等
                - 提供了丰富的样式设置接口


    1.2 安装与环境配置
        使用pip安装（推荐）
            pip install matplotlib
        使用conda安装
            conda install matplotlib
        验证安装
            import matplotlib
            print(f"Matplotlib版本: {matplotlib.__version__}")


    1.3 中文字体设置（关键技巧）
        由于 Matplotlib 默认不支持中文字体，需要进行配置
            - plt.rcParams['font.sans-serif'] = ['SimHei']：这是最关键的一行。
                    SimHei 是“黑体”的英文名，也是 Windows 系统自带的字体。这行代码告诉 Matplotlib：“以后遇到文字，优先用黑体来显示。”
            - plt.rcParams['axes.unicode_minus'] = False：Matplotlib 默认使用 Unicode 编码的减号（-），
                    某些中文字体不支持这个特殊符号，会导致负号也变成方框。将其设为 False 后，它会改用普通的连字符（hyphen），从而完美显示负号。

        通过字体文件的绝对路径（fname）加载一个特定的字体
            - 这是一种“指哪打哪”的方法。它不改变全局设置，而是直接通过字体文件的绝对路径（fname）加载一个特定的字体。
-           - 使用时，你需要在具体的绘图函数里单独指定，例如：plt.title("中文标题", fontproperties=font)。
                    这种方法适合只想让某几个特定的文字使用特殊字体（比如艺术字或特定品牌的定制字体）的场景。

        带“备选方案”的动态设置（最稳健）
            - 它一次性更新了一组配置，并且为字体设置了“备选名单”。
            - 执行逻辑：Matplotlib 会按顺序从左到右寻找字体。它会先找 SimHei（适合 Windows），
                    如果你的电脑是 Mac 没有黑体，它就会自动跳过，去尝试找 Arial Unicode MS（适合 macOS），
                    最后如果都没有，才退回到默认的 DejaVu Sans。
            - 这种写法写出的代码跨平台兼容性极强，把你的代码发给用 Mac 或 Linux 的同事，他们直接运行也不会报错或出现乱码。

        如果是在 Windows 电脑上日常做数据分析或画图，直接复制方法3的代码放在所有绘图脚本的最开头，基本就能一劳永逸地解决中文乱码和负号显示问题


    1.4 基本使用流程
        Matplotlib 提供两种使用风格：
        面向对象风格（推荐）：
            核心特征是：显式地创建并操作“对象”，通过调用这些对象自带的“方法”来完成绘图。
            代码中具体体现在以下几个关键点：
                1. 显式创建对象 (Explicit Object Creation)
                    直接把绘图的核心元素——Figure（画布对象）和 Axes（坐标轴/子图对象）——显式地创建出来，并赋值给了变量 fig 和 ax
                2. 通过对象调用方法 (Calling Methods on Objects)
                    在拿到 ax 和 fig 这两个对象后，后续几乎所有的操作都是通过 对象.方法() 的形式来执行的：
                        - 绘图：ax.plot(...) —— 明确告诉 ax 这个坐标轴对象：“请你画出这条线”。
                        - 设置属性：ax.set_xlabel(...)、ax.set_title(...)、ax.legend()、ax.grid(...)
                                —— 都是在直接指挥 ax 对象去修改它自己的标签、标题、图例和网格。
                        - 保存文件：fig.savefig(...) —— 指挥最外层的 fig 画布对象把自己保存成一张图片。

        pyplot 风格（快速交互）
            “傻瓜相机”模式。在这种模式下，不需要关心画布（Figure）和坐标轴（Axes）这些具体的对象，只需要直接向 plt 下达指令
            （比如 plt.plot(), plt.title()），Matplotlib 会在后台自动创建画布，并默默记住“当前正在操作的是哪张图、哪个坐标系”。
            它最大的特点就是代码简短，全程使用 plt. 开头
            写复杂项目时推崇面向对象（OO）风格，但过程式风格在以下几种场景中非常好用，甚至更高效：
                1. 快速探索数据（如 Jupyter Notebook 中）
                    当你在做数据分析的初期，只是想快速看一眼数据的分布或趋势，不需要精美的排版。
                    用 plt 几行代码就能立刻出图，非常顺手。
                2. 绘制极其简单的单张图表
                    如果你只需要画一张图，且图上只有一个坐标系（没有复杂的子图拼接），过程式风格写起来最快，代码也最简洁。
                3. 编程入门或教学演示
                    对于刚接触 Matplotlib 的新手，面向对象中 fig 和 ax 的概念可能会增加理解门槛。
                    过程式风格逻辑直观（像流水账一样），非常适合用来学习基础的绘图函数。

        总结：
            如果只是随便画个图看看，或者画非常简单的单图，直接用 plt 的过程式风格完全没问题，怎么快怎么来；
            但如果你要写正式的分析脚本、做复杂的仪表盘或者批量出图，请务必切换回面向对象（fig, ax）风格。


二、基础图表类型详解


    2.1 折线图（Line Plot）
        折线图是最基本的图表类型，用于显示数据随时间或有序类别变化的趋势。

        基本语法：
            plt.plot(x, y, format_string, **kwargs)

        format_string 参数：
            颜色：’b’（蓝色）、’g’（绿色）、’r’（红色）、’c’（青色）、’m’（品红）、’y’（黄色）、’k’（黑色）、’w’（白色）
            线型：’-‘（实线）、’—‘（虚线）、’-.’（点划线）、’:’（点线）
            标记：’.’（点）、’,’（像素点）、’o’（圆圈）、’v’（下三角）、’^’（上三角）、’s’（正方形）、’*‘（星号）

        综合示例:
            Line Plot

        关键参数说明：
            - linewidth：线条宽度（单位：点）
            - markersize：标记大小（单位：点）
            - markeredgecolor：标记边缘颜色
            - markerfacecolor：标记填充颜色
            - alpha：透明度（0-1）

    补充：
        fig, ax = plt.subplots()
            fig 是整张画纸，ax 是画纸上的坐标轴（画板），画画都是在 ax 上画
            plt.subplots() 这个函数本身就返回一个元组：(画布对象, 坐标轴对象)，用解包赋值，分别给到 fig 和 ax。

                - fig → Figure 画布 / 画纸
                    整张画布、整张图片容器
                    管整体：尺寸、保存图片、整体布局
                    不直接用来画线、画点
                    专属操作：
                        fig.savefig("xxx.png")  # 保存整张图
                - ax → Axes 坐标系 / 绘图区
                    - 就是带 X 轴、Y 轴 的那块绘图区域
                    - 真正画图都用 ax
                    - 所有绘图、设置都往 ax 上操作：
                        ax.plot()         # 画曲线
                        ax.set_xlabel()   # x轴标签
                        ax.set_title()    # 标题
                        ax.legend()       # 图例
                        ax.grid()         # 网格

            总结、
                1. plt.subplots() 返回 (Figure, Axes) 两个对象
                2. fig = 整张画布，只用来保存、管整体
                3. ax = 坐标轴绘图区，所有画图、设标签、标题、网格都用它
                4. 画图永远记住：在 ax 上画，用 fig 保存，用 plot 显示

        一些方法的功能(虽然一些不查也能看明白，查一下更全面嘛)
        1. plt.subplots(figsize=(10, 6))
            作用：创建一张画布 + 一个坐标系
                - fig = 整张图（画布）
                - ax = 坐标系（画图区域）
                - figsize=(10,6)：画布大小 10×6 英寸
            返回两个东西：画布 + 坐标区
        2. np.linspace(0, 10, 100)
            生成等差数列
                - 从 0 到 10
                - 均匀生成 100 个点
        3. np.sin(x)
            计算正弦值输入 x，输出 sin (x)，得到 Y 轴数据。
        4. ax.plot(x, y, 'b-', linewidth=2, label='sin(x)')
            核心绘图函数：画折线图
                - x, y：数据
                - 'b-'：蓝色实线
                    b = blue
                    - = 实线
                - linewidth=2：线条粗细
                - label='sin(x)'：图例名称
        5. ax.set_xlabel() / ax.set_ylabel()
            设置 X 轴、Y 轴标签
                - fontsize=12：字体大小
        6. ax.set_title()
            设置图表标题
                - fontweight='bold'：加粗
        7. ax.legend()
            显示图例会自动使用 plot(..., label='xxx') 里的名字。
        8. ax.grid()
            显示网格线
                - alpha=0.3：透明度（越接近 0 越淡）
        9. plt.show()
            弹出窗口显示图表必须写，否则图不出来。
        10. fig.savefig()
            保存图片到文件
                - dpi=300：高清画质
                - bbox_inches='tight'：裁剪白边
        11. ax.set_xlim() 和 ax.set_ylim()
            手动设置 X 轴 / Y 轴 的显示范围
                - ax.set_xlim(最小值, 最大值)
                - ax.set_ylim(最小值, 最大值)
            作用
                让图表留白更美观
                控制显示区域，不让数据贴在边框上
                突出重点区间
        12. ax.axhline()
            画一条横跨整个图表的水平参考线
            参数解释
                - y=0：在 Y=0 的位置画线
                - color='gray'：颜色灰色
                - linestyle='-'：实线
                - linewidth=1：线宽
            同类函数（拓展）
                - ax.axhline() → 水平线
                - ax.axvline() → 垂直线
                - 常用于：0 轴线、基准线、阈值线、警戒线
        13. plt.tight_layout()
            自动调整图表内边距、子图间距，让标签、标题不重叠、不裁切
            解决的问题：
                - 防止标题、轴标签超出图片范围
                - 防止多个子图互相挤压
                - 让整个图更整洁、美观
            自动排版，让图好看不挤！
        14. loc='upper right' 参数
            把图例（legend）放到坐标系的 右上角，单词原意
            常用 9 个位置（直接背这几个够用）
                - upper right / loc=1     右上角
                - upper left  / loc=2     左上角
                - lower right / loc=3     右下角
                - lower left  / loc=4     左下角
                - upper center    上居中
                - lower center    下居中
                - center left     左居中
                - center right    右居中
                - center          正中间
            其实就是 upper/lower/center right/left/center 的排列组合
            如果不想固定位置，想让 Matplotlib 自动找不遮挡曲线的地方：
                ax.legend(loc='best')
                它会自动选空隙最大的位置放图例


    2.2 柱状图（Bar Chart）
        柱状图用于比较不同类别之间的数据大小。

        基本语法：
            plt.bar(x, height, width=0.8, bottom=None, **kwargs)  # 垂直柱状图
            plt.barh(y, width, height=0.8, left=None, **kwargs)   # 水平柱状图

    补充：
        ax.bar(位置, 高度, 宽度, 标签, 颜色)
        ax.bar(第一个参数) 传入的就是柱子中心点的 x 坐标
        ax.set_xticks(x) 设置 x 轴下的小竖线，下的值
        ax.set_xticklabels(categories) 把上面的值换成 categories 中的值

        bars1 = ax.bar(x - width/2, sales_2023, width, label='2023年', color='#1f77b4')
            - 返回值：BarContainer（柱子容器）
            - 内部：包含 N 个 Rectangle 对象，N = 画的柱子数量
            - 用法：像数组 / 列表一样使用

        bottom 参数 作用
            bottom 就是：每根柱子「底部从哪个高度开始往上画」
            默认不写 bottom 时：
                - 柱子底部默认在 y=0，从 0 往上长到你的数值高度。
            给了 bottom 后：
                - 柱子底部不再从 0 开始，从你指定的 bottom 位置往上长。

        bar.get_x() + bar.get_width() / 2.
            柱子左边缘位置 + 半根柱子宽度 = 柱子正中心 X 坐标
            目的：让文字水平落在柱子正中间。
        y_pos
            就是把文字放在哪个高度。
            常见两种玩法：
                - 放柱子顶部上方：y_pos = height
                - 放柱子垂直正中间：y_pos = height / 2
        f'{int(height)}'
            把柱子高度转成整数字符串，作为要画的文字
        ha='center'
            ha = horizontal alignment 水平对齐
            以给的 X 坐标 为中心，文字水平居中对齐。
            配合前面算的柱子中心 X，完美居中。
            其他可选：
                - ha='left' 文字左对齐
                - ha='right' 文字右对齐
        va='center'
            va = vertical alignment 垂直对齐
            以给的 Y 坐标 为中心，文字垂直居中。
            其他可选：
                - va='bottom' 文字底部贴在 Y 位置
                - va='top' 文字顶部贴在 Y 位置

        ax.text(
            柱子中心X坐标,   # 水平位置：柱子正中间
            指定的Y高度,    # 垂直位置
            要显示的数字,
            ha='center',    # 文字自身水平居中
            va='center'     # 文字自身垂直居中
        )

        柱子顶部标数字(常用)
        for bar in bars1:
            height = bar.get_height()
            ax.text(
                bar.get_x() + bar.get_width() / 2,
                height,        # y放在柱子顶端
                f"{int(height)}",
                ha="center",
                va="bottom"    # 文字底部贴着柱子顶
            )


    2.3 饼图（Pie Chart）
        饼图用于显示数据的比例分布。

        基本语法：
            plt.pie(x, explode=None, labels=None, colors=None, autopct=None, shadow=False, startangle=0, **kwargs)

        高级饼图技巧：
            - 使用autopct参数格式化百分比显示
            - 使用explode参数突出显示特定部分
            - 使用shadow参数添加阴影效果
            - 使用startangle参数设置起始角度

    补充：
        plt.pie(
            x,                   # 必须：饼图每一块的数值
            explode=None,        # 可选：是否把某块“拉出来”
            labels=None,         # 可选：每块的标签文字
            colors=None,         # 可选：每块的颜色
            autopct=None,        # 可选：显示百分比格式
            shadow=False,        # 可选：是否显示阴影
            startangle=0,        # 可选：饼图起始角度
            **kwargs             # 其他高级参数
        )
        1. x（必须传）
            - 作用：饼图每一块的大小数据
            - 传入：列表 / 数组
            - 注意：不用自己算百分比，matplotlib 自动算
        2. explode（突出某一块）
            - 作用：把某一块往外拉出来一点（强调用）
            - 传入：列表，长度必须和 x 一样
            - 0 = 不突出，数字越大突出越远
        3. labels（每块的标签）
            - 作用：给每块加名字
            - 长度必须 = len(x)
            - 否则报你刚才那个错：ValueError: 'label' must be of length 'x'
        4. colors（颜色）
            - 作用：自定义每块颜色
            - 列表长度必须和 x 一样
        5. autopct（显示百分比 ✨ 最常用）
            - 作用：自动在饼图内部显示百分比
            - 格式写法：
                %.1f%% → 保留 1 位小数 + 百分号
                %.2f%% → 保留 2 位小数
                %d%% → 整数
        6. shadow（阴影）
            - True：有阴影（立体一点）
            - False：无阴影（默认）
        7. startangle（起始角度）
            - 作用：旋转整个饼图
            - 默认 0°：从 x 轴正方向开始画(逆时针)
            - 常用 startangle=90：从顶部开始画（更好看）
            - 想顺时针：加 counterclock=False

        1、 wedges, texts, autotexts = ax.pie(...)
            1. wedges → 饼图的「扇形块」
                - 类型：饼图的每一块扇形（Patches）
                - 作用：所有扇形的列表
                - 你有几块饼，wedges 里就有几个对象
                能用来干什么？
                    - 改某块的颜色
                        wedges[0].set_color('red')  # 把第一块改成红色
                    - 改边框
                    - 改透明度
                    - 突出显示某一块
            2. texts → 饼图旁边的「标签文字」
                就是 labels=['A','B','C'] 显示在饼图外面的文字。
                    - 类型：文本对象列表
                    - 对应：每一个 label
                    - 作用：控制外面标签的样式（字体、大小、颜色）
            3. autotexts → 饼图内部的「百分比文字」
                就是 autopct='%1.1f%%' 显示在扇形内部的数字。
                    - 类型：文本对象列表
                    - 对应：每块内部的百分比
                    - 作用：修改内部百分比的样式


    2.5 直方图（Histogram）
        直方图用于显示数据的分布情况。

        基本语法：
            plt.hist(x, bins=10, range=None, density=False, alpha=0.7, \*\*kwargs)

        二维直方图 hist2d
            把 X-Y 平面分成很多小格子，统计每个格子里有多少个点，
            用颜色深浅表示数量多少 → 这就是二维直方图！
            X、Y：坐标点
                - 颜色越深：点越多 / 密度越大
                - 颜色越浅：点越少

        类型	    统计维度	    表现形式
        hist	1 维（x）	柱子高度
        hist2d	2 维（x,y）	颜色深浅
        
        可以：
            - 改成热力图样式
            - 加等高线
            - 画离散数据分布

    补充：
        1. data
            要统计的数据（列表、数组）
        2. bins
            柱子数量
                - 越大 → 柱子越细
                - 越小 → 柱子越粗
        3. alpha
            透明度（0~1）让图更好看，不刺眼
        4. color & edgecolor
            - color：柱子填充色
            - edgecolor：柱子边框色（黑色最清晰）
        5. label
            图例文字，配合 ax.legend() 使用

        fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 6))
            创建了 1 行 2 列的画布(宽度 14，高度 6)，一共 2 个独立的坐标系（坐标轴）

        1、 hist2d 参数详解
            1. x, y
                必须传的两组数据，一一对应，代表平面上的点。
            2.bins=30
                X、Y 方向各分成 30 份→ 总格子数：30×30=900 个
            3. cmap='Blues'颜色映射（配色方案）
                - Blues：蓝色系
                - Reds：红色系
                - Greens：绿色系
                - viridis：彩虹色（默认）
            4. density=True
                - True：显示概率密度（总和 = 1）
                - False：显示每个格子里的点数量（默认）

        2、 hist2d 的返回值（非常重要）
            返回 4 个值（元组）：

    补充：
        1. 固定随机种子
            np.random.seed(42)
            每次运行生成的随机点一模一样，方便复现。
        2. 生成数据
            x = np.random.rand(N)
            np.random.rand(N) 生成 [0,1) 之间均匀分布 的 N 个随机数
        3. 随机颜色
            colors = np.random.rand(N)
            生成 100 个 0~1 数值，每个数值对应一个点的颜色映射值配合
                cmap 自动渐变上色。
        4. 随机大小
            sizes = 1000 * np.random.rand(N)
                - np.random.rand(N) → 0~1
                - 乘 1000 → 点的大小范围 0 ~ 1000，所以每个散点大小完全不一样。

        5. 核心：ax.scatter 参数精讲
            scatter = ax.scatter(
                x, y,
                s=sizes,        # 每个点的大小
                c=colors,       # 每个点的颜色映射值
                cmap='viridis', # 配色方案
                alpha=0.7,      # 整体透明度
                edgecolors='black', # 点的边框颜色
                linewidth=1     # 边框粗细
            )
                - s：点大小，可以传列表 / 数组 → 每个点大小不同
                - c：颜色映射值，传数组 → 配合 cmap 渐变着色
                - cmap='viridis'：经典彩虹渐变色
                - alpha=0.7：半透明，点重叠也能看清
                 -edgecolors='black'：每个圆点加黑色描边，轮廓更清晰
                - linewidth=1：描边宽度

        6. 颜色条
            cbar = plt.colorbar(scatter)
            cbar.set_label('颜色映射值', fontsize=10)
            - 把散点的颜色数值刻度显示在右侧
            - 告诉看图的人：什么颜色对应多大的 colors 值

        7. colors = np.random.rand(N) 为什么能当颜色？
            它不是直接当颜色，而是当「颜色的序号 / 数值」，
            matplotlib 会根据这个数字，自动从 cmap（配色板）里取对应的颜色！
            - np.random.rand(N) → 生成 0~1 之间的数值
            - 你写了 cmap='viridis' → 这是一整条渐变色谱
            - matplotlib 自动做一件事：
                数字越小 → 取色谱左边的颜色
                数字越大 → 取色谱右边的颜色
                colors 数值：  0.1   0.5   0.9
                              ↓     ↓     ↓
                viridis色板： 深紫 → 浅蓝 → 黄亮
            colors 不是颜色本身，是「颜色位置索引」！

        8. 为什么 sizes=1000*np.random.rand(N)，点却不大？
            scatter 里的 s= 不是直径，是「点的面积」！
            单位是 像素平方（pixel²）
                - s = 1000 → 面积 = 1000
                - 直径 ≈ sqrt (1000) ≈ 31.6 像素
            看到的点直径大约 0.05（坐标单位），是因为坐标范围是 0~1，图上像素很多，所以坐标单位看起来很小！
                - s=100 → 很小
                - s=500 → 中等
                - s=1000 → 很大
            sizes = 1000 * np.random.rand(N)，点面积从 0 ~ 1000 随机，非常合理！


两个问题:
    1、 plt.subplots，返回画布对象，坐标轴对象，在坐标轴上画图，但显示图像时使用plt.show()，没有涉及到画布对象，是因为.show（）默认显示所有的画布对象吗？
        plt.show () 会自动显示当前所有已创建的画布（figure），不需要手动传入 fig！
        fig, ax = plt.subplots(figsize=(10,8))
        这句做了两件事：
            - 创建一个画布 fig
            - 创建一个坐标轴 ax 放在画布上
            - matplotlib 内部自动记住了这个画布
        ax.scatter(...)
            - 所有图都画在 fig 里面的 ax 上
        plt.show()
            _ matplotlib 会把当前所有创建过的画布，全部显示出来！

        为什么不需要用 fig.show ()？
            - plt.show () 是全局显示函数
            - 它会自动找到 当前所有 figure 画布
            - 自动展示它们
            所以你不需要手动调用 fig.show ()甚至不需要把 fig 赋值给变量，下面这样也能跑:
                plt.subplots()  # 不写 fig, ax = ...
                ax = plt.gca()  # 获取当前轴
                ax.plot([1,2,3])
                plt.show()      # 照样显示！

        只有一种情况需要用 fig.show (),在 Jupyter Notebook 以外的某些 GUI 环境里
        但日常写代码 99% 都只用 plt.show ()

    2、 为什么设置接受返回值的变量时如果变量名都是fig, ax，最后显示的绘图不会相互影响？
        因为每次执行 plt.subplots ()，都会创建一块【全新、独立】的画布！
        后面的 fig, ax 变量，会【重新指向】新画布，不会覆盖、不会影响前面的图！
        fig, ax = plt.subplots()
            都会发生 3 件事：
            1. 创建一张新画布（新 Figure）
                - 和之前的画布完全无关
                - 有自己独立的内存、独立的坐标系
                - 就像你拿了一张新的画纸
            2. 创建一个新的坐标轴（新 Axes）
                - 画在新画纸上
            3. 把新画布、新坐标轴 赋值给 fig, ax
                - 变量名虽然一样，但指向的是【新对象】！
                - 旧的图已经保存在内存里了，不会被删掉
                - fig, ax 只是 “名字标签”
                - 第一次：指向 画布 1
                - 第二次：指向 画布 2
                - 画布 1 还静静地待在内存里，没有消失！

            Python 的 Pandas 和 Seaborn 库内置了极其强大的散点图矩阵绘制函数，一行代码就能完美实现，且自带图例和美化。

        10. df = pd.DataFrame(iris.data, columns=iris.feature_names)
            将 scikit-learn 提供的原始数据，转换成一个带有漂亮表头的、标准的 Pandas 表格（DataFrame）
            可以把它拆解成三个部分来理解：
            1. iris.data（原材料）
                当使用 load_iris() 加载鸢尾花数据集时，它返回的 iris.data 本质上是一个 150行 x 4列的纯数字矩阵（通常是 NumPy 数组）。
                它里面只有冷冰冰的数值，比如 5.1, 3.5, 1.4, 0.2，并没有直接表明这些数字分别代表什么。
            2. columns=iris.feature_names（贴标签）
                iris.feature_names 是一个包含 4 个字符串的列表，它提供了这 4 列数据的标准名称：
                ['sepal length (cm)', 'sepal width (cm)', 'petal length (cm)', 'petal width (cm)']
                （即：花萼长度、花萼宽度、花瓣长度、花瓣宽度）
                把它传给 columns 参数，就相当于给上面的纯数字矩阵贴上了清晰的“列名标签”。
            3. pd.DataFrame(...)（装进表格）
                pd.DataFrame 是 Pandas 库中最核心的二维表格数据结构。
                这一步就是把“纯数字矩阵”和“列名标签”组装起来，变成一个功能强大的 Pandas 表格对象，并赋值给变量 df。
            这样做：
                - 可读性极强： Excel 一样带表头的清晰表格
                - 操作更方便：有了 DataFrame，你就可以通过列名直接提取数据
                - 功能更强大：Pandas 提供了极其丰富的数据分析函数
                        （比如 df.describe() 一键生成统计摘要，df.plot() 直接绘图等），这些是原始的数字矩阵所不具备的。

            axes[idx].scatter(...)
                在索引为 idx 的特定子图上绘制散点图。

            df[features[j]] 和 df[features[i]]
                散点图矩阵的精髓在于两两特征的对比。
                这里通过循环变量 i 和 j，分别提取鸢尾花的两个不同特征（比如“花萼长度”和“花瓣宽度”）作为 X 轴和 Y 轴的数据。

            c=df['target'].map(lambda x: colors[x])
                这是给点上色的关键。df['target'] 里存的是 0, 1, 2 这样的类别数字(代表花的种类)。
                map(lambda x: colors[x]) 的作用就是把 0 映射成 colors[0]（红色），1 映射成 colors[1]（绿色），以此类推。
                这样不同种类的鸢尾花在图上就会显示为不同的颜色。
            alpha=0.6
                设置点的透明度。因为散点图可能会有很多点重叠在一起，设置一定的透明度可以让你更清楚地看到数据点的密集程度。

            axes[idx].set_xlabel(features[j], fontsize=8)
            axes[idx].set_ylabel(features[i], fontsize=8)
                给当前的子图加上 X 轴和 Y 轴的标题（比如 "sepal length (cm)"）。
                fontsize=8 用来控制标签字体的大小，防止字太大在矩阵图中显得拥挤。

            axes[idx].axis('off')
                执行后，这个子图的 X 轴、Y 轴、刻度线、刻度数字以及边框线都会全部消失，只留下画布中间的散点图。
                实际使用建议：在散点图矩阵中，通常不建议对所有的子图都使用 axis('off')。
                        因为如果把所有坐标轴都关了，就不知道每个子图对应的具体数值范围了。
                一般会保留最左侧一列子图的 Y 轴，和最下方一行子图的 X 轴，只把矩阵内部（非边缘）子图的坐标轴隐藏掉，这样既能保持图表整洁，又能看清数据刻度。
