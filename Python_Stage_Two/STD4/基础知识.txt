面向对象编程（OOP）总结

    1. 面向对象编程基础概念
        1.1 类与对象的定义及关系
            面向对象编程（Object-Oriented Programming, OOP）是一种基于 "对象" 概念的编程范式，
            它将数据（属性）和操作数据的方法（行为）封装在一个单元中，通过对象之间的交互来实现程序功能。

                类（Class）：是对象的蓝图或模板，定义了一类对象的共同特征和行为。类是一个抽象概念，它不包含实际的数据。
                    例如，"汽车" 可以被定义为一个类，它包含了所有汽车共有的属性（如品牌、型号、颜色）和方法（如启动、加速、刹车）。
                对象（Object）：是类的具体实例，是根据类创建出来的具体实体。对象具有类定义的属性和方法，但拥有具体的属性值。
                    例如，"我的红色宝马汽车" 就是 "汽车" 类的一个具体对象，它具有特定的品牌（宝马）、颜色（红色）等具体属性。

            类与对象的关系可以用一个形象的比喻来说明：类就像是一张设计图纸，而对象则是根据这张图纸制造出来的具体产品。
            你可以根据同一张设计图纸制造出多个产品，每个产品都具有相同的基本结构，但可能有不同的外观和配置。

            在 Python 中，使用class关键字来定义类：
                class Dog:
                    pass  # 空类定义

            创建对象（实例化）的方式是调用类名并添加括号：
                my_dog = Dog()  # 创建Dog类的一个对象
                another_dog = Dog()  # 创建另一个Dog类的对象

        1.2 实例属性与类属性
            在 Python 类中，属性分为两种类型：实例属性和类属性。
            实例属性是每个对象独有的属性，它们在__init__方法中通过self关键字定义。实例属性的值在不同对象之间可以不同。
                class person

            类属性是所有对象共享的属性，它们定义在类中但在任何方法之外。类属性属于类本身，而不是单个对象。
                class person2

        1.3 实例方法、类方法与静态方法

            在 Python 类中，方法也分为三种类型：实例方法、类方法和静态方法。

            实例方法是最常见的方法类型，它只能通过对象调用，第一个参数必须是self，代表当前对象本身。
                实例方法可以访问实例属性和类属性。
                    class person3

            类方法使用@classmethod装饰器定义，第一个参数是cls，代表类本身。
                类方法可以访问类属性，但不能访问实例属性。
                    class person4

            静态方法使用@staticmethod装饰器定义，它既不需要self参数也不需要cls参数。
                静态方法不能访问实例属性和类属性，通常用于与类相关但不依赖于类状态的功能。
                    class MathUtils

            三种方法的对比总结：
                方法类型	装饰器          	第一个参数	访问实例属性	访问类属性	调用方式
                实例方法	无            	self 	    可以    	    可以   	    对象.方法()
                类方法 	@classmethod 	cls  	    不可以   	可以   	    类.方法() 或对象.方法()
                静态方法	@staticmethod	无    	    不可以   	不可以  	    类.方法() 或对象.方法()


    2. OOP 四大核心特性详解
        2.1 封装（Encapsulation）
            封装是 OOP 的核心特性之一，它指的是将数据和操作数据的方法捆绑在一个独立的单元（类）中，并隐藏对象的内部细节，只对外提供必要的接口。
            封装的核心思想是 "把该隐藏的隐藏，该暴露的暴露"。
            对象的属性（尤其是核心属性）不应该被外部直接修改，而是通过类提供的方法（getter/setter）来访问和修改，这样可以在方法中添加校验逻辑，确保数据的合法性。
            在 Python 中，封装通过命名约定实现，主要有三种访问级别：
                1. 公有成员：没有特殊前缀，可以在任何地方访问
                    class BankAccount
                2. 保护成员：以单下划线开头（如_name），表示仅供类内部或子类使用
                    class BankAccount2
                3. 私有成员：以双下划线开头（如__name），通过名称重整机制实现访问限制
                    class BankAccount3
                    Python 的私有成员通过名称重整（name mangling）机制实现，__balance实际上会被重命名为_BankAccount__balance，
                    但这种方式不应该被依赖或使用。

        2.2 继承（Inheritance）
            继承是 OOP 的第二个核心特性，它允许一个类（子类）继承另一个类（父类）的属性和方法，从而实现代码的复用和扩展。
            在继承关系中，子类可以继承父类的所有公有和保护成员，但不能继承私有成员。
            子类还可以添加自己的属性和方法，或者重写父类的方法。
                单继承示例
