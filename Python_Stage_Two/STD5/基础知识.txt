Python 正则表达式基础语法体系

    1.1 正则表达式核心概念与 re 模块
        正则表达式（Regular Expression，简称 Regex）是一种描述字符串模式的语法规则，被誉为文本处理的 "瑞士军刀"。
        在数据驱动的时代，原始数据中充斥着大量 "噪音"—— 无关字符、不规则格式、隐藏的异常值，
        正则表达式凭借其强大的模式匹配能力，能够高效地完成文本清洗、信息提取、格式验证等任务。

        Python 的re模块提供了完整的正则表达式支持，是标准库中处理正则表达式的核心工具，提供强大的文本模式匹配、搜索和替换功能。
        在 Python 中使用正则表达式，必须先导入re模块：
            import re  # 导入正则表达式模块

    1.2 核心元字符详解
        元字符是正则表达式中具有特殊意义的字符，用于构建匹配模式。掌握核心元字符是编写正则表达式的基础：
            元字符   说明                           	        示例             匹配结果
              .    	匹配除换行符外的任意字符                 	r"a.c"     	    匹配 "abc"、"aec" 等
              ^    	匹配字符串开头                      	    r"^Hello"  	    匹配以 "Hello" 开头的字符串
              $    	匹配字符串结尾                      	    r"world$"  	    匹配以 "world" 结尾的字符串
              *    	匹配前一个字符零次或多次（贪婪匹配）           r"ab*"     	    匹配 "a"、"ab"、"abb" 等
              +    	匹配前一个字符一次或多次（贪婪匹配）           r"ab+"     	    匹配 "ab"、"abb"、"abbb" 等（不匹配 "a"）
              ?    	匹配前一个字符零次或一次                 	r"ab?"     	    匹配 "a" 或 "ab"
              {n}  	匹配前一个字符恰好 n 次                	    r"a{3}"    	    匹配 "aaa"
              {n,m}	匹配前一个字符 n 到 m 次              	    r"a{3,5}"  	    匹配 "aaa"、"aaaa"、"aaaaa"
              [ ]  	匹配括号内的任意一个字符                 	r"[aeiou]" 	    匹配任意元音字母
              [^ ] 	匹配不在括号内的任意一个字符               	r"[^aeiou]"	    匹配任意非元音字母
              \d   	匹配任意数字（等价于 [0-9]）            	r"\d{3}"   	    匹配三位数字
              \w   	匹配字母、数字、下划线（等价于 [a-zA-Z0-9_]）	r"\w+"     	    匹配单词字符序列
              \s   	匹配空白字符（空格、制表符、换行符等）          r"\s+"     	    匹配一个或多个空白字符
              |    	逻辑 "或" 操作  	                        r"(cat|dog)"    匹配"cat" 或 "dog"
              ()   	分组捕获                         	        r"(ab)+"   	    匹配 "ab"、"abab"、"ababab" 等

        贪婪匹配与非贪婪匹配是正则表达式中一个极易被忽视但影响巨大的概念：
            - 贪婪模式（默认）：量词*、+、{n,}会尽可能多地匹配字符,即最长匹配
            - 非贪婪模式：在量词后添加?，使其尽可能少地匹配字符,即最短匹配

        以字符串<div>content<div>为例：
            - 贪婪模式<.*>会匹配整个<div>content</div>（从第一个<到最后一个>）
            - 非贪婪模式<.*?>只会匹配<div>（遇到第一个>即停止）

    1.3 Python re 模块核心函数
        Python 的re模块提供了多个核心函数，每个函数都有其特定的使用场景：
            函数                                      	    描述            	        返回值           	常用场景
            re.match(pattern, string, flags=0)      	    从字符串起始位置匹配    	Match 对象或 None	验证字符串开头格式
            re.search(pattern, string, flags=0)     	    扫描整个字符串找到第一个匹配	Match 对象或 None	查找特定模式
            re.findall(pattern, string, flags=0)    	    返回所有匹配结果组成的列表 	列表            	    提取所有符合条件的内容（最常用）
            re.sub(pattern, repl, string, count=0, flags=0)	替换匹配内容        	    替换后的字符串       	数据清洗、格式转换
            re.split(pattern, string, maxsplit=0, flags=0)	根据匹配分割字符串     	    分割后的列表        	复杂字符串分割

        补充：
            flags=0 代表不开启任何正则修饰标志，使用正则默认匹配规则。
            常见修饰标志：
                - re.IGNORECASE / re.I：忽略大小写
                - re.MULTILINE / re.M：多行模式
                - re.DOTALL / re.S：. 匹配换行符
            不传、默认 flags=0 = 所有修饰都关闭，纯默认规则匹配。

            re.split(pattern, string, maxsplit=0, flags=0)，分割后不包含模式串
            如果 string 的开头就匹配 pattern 会切出一个空字符串 ‘’

        预编译正则表达式：当需要多次使用同一正则表达式时，使用re.compile()预编译可以显著提升性能：

    1.4 匹配模式（flags 参数）
        re模块提供了一些标志参数，可以改变匹配行为：
        flags 是正则匹配模式修饰符，用来改变正则元字符、^ $ . 等的默认行为。可以单个用、多个用 | 叠加，默认 flags=0 不开启任何模式。
        常用 6 大标志：
            1. re.IGNORECASE / re.I
                忽略大小写匹配
            2. re.MULTILINE / re.M
                多行模式
                改变 ^ 和 $ 含义：
                默认：^ 只匹配整个字符串开头，$ 只匹配整个字符串结尾
                开多行模式：
                    ^ 匹配每一行的行首
                    $ 匹配每一行的行尾
            3. re.DOTALL / re.S
                让 . 匹配换行符 \n
                默认：. 不能匹配换行
                开 re.S：. 可以匹配任意字符（包括换行）
                最常用场景：跨行贪婪 / 非贪婪匹配
            4. re.VERBOSE / re.X
                冗长模式，正则可以写注释、换行、空格
                把复杂正则拆开写，加 # 注释，忽略正则里的空白和注释。
            5. re.ASCII / re.A
                让 \w \d \s 等只匹配 ASCII 字符
                默认：\w 会匹配中文汉字、全角字符
                加 re.A：只匹配英文字母、数字、下划线
            6. re.LOCALE / re.L
                本地化模式，根据系统本地语言匹配字符，几乎不用。

        多个标志同时使用：
            用 | 竖线 叠加
            # 忽略大小写 + .匹配换行
            res = re.findall(r'xxx', text, re.I | re.S)

        默认 flags=0 意义：
            不开启任何修饰模式，所有元字符、^ $ . 都按默认原始规则匹配。

        标志	            简写	    作用
        re.IGNORECASE	re.I	忽略大小写
        re.MULTILINE	re.M	^ $ 匹配每行首尾
        re.DOTALL	    re.S	. 匹配换行符
        re.VERBOSE	    re.X	正则可换行加注释
        re.ASCII	    re.A	\w 只匹配 ASCII
        日常写正则 最常用就三个：I、M、S

    2.3 格式转换实战
        不同来源的数据格式往往不一致，正则表达式可用于统一格式。

        日期格式转换
            将 "MM/DD/YYYY" 格式转换为 "YYYY-MM-DD" 格式

            补充：
                第一步：正则里的 () = 分组
                    (\d{2})/(\d{2})/(\d{4})
                这里有 3 对小括号 ()，就是 3 个分组：
                    第 1 组 (\d{2}) → 捕获 月份 05
                    第 2 组 (\d{2}) → 捕获 日期 20
                    第 3 组 (\d{4}) → 捕获 年份 2024
                第二步：\数字 = 反向引用
                在 re.sub 的 ** 第二个参数（替换模板）** 里：
                    \1 = 取出第 1 组捕获的内容
                    \2 = 取出第 2 组捕获的内容
                    \3 = 取出第 3 组捕获的内容

                为什么可以直接写 r"\3-\1-\2"？
                原因只有 2 个：
                    1. 前面用 () 分了组，Python 自动记住了每组内容
                    2. re.sub 专门支持 \1 \2 \3 语法，用来引用前面捕获的分组
                这是正则内置标准功能，全世界通用！

        大小写规范化
