项目需求分析
    本实战项目将开发一个学生成绩管理系统，系统需要支持以下功能：
        1. 学生管理：添加学生、查询学生信息、删除学生
        2. 成绩管理：录入成绩、查询成绩、计算平均成绩
        3. 课程管理：添加课程、管理课程信息
        4. 统计分析：计算班级平均分、排名等
    项目将采用面向对象设计，充分体现 OOP 的四大特性和设计原则。

系统设计
    类设计：
        1. Student 类：表示学生，包含姓名、学号、成绩等属性
        2. Course 类：表示课程，包含课程名称、学分等属性
        3. Grade 类：表示成绩，关联学生和课程
        4. School 类：表示学校，管理所有学生和课程

    类图设计：
        School
            ├── students: List[Student]
            ├── courses: List[Course]
            ├── add_student(student: Student)
            ├── add_course(course: Course)
            ├── add_grade(grade: Grade)
            └── calculate_class_average()
        Student
            ├── student_id: str
            ├── name: str
            ├── grades: List[Grade]
            ├── add_grade(grade: Grade)
            └── calculate_gpa()
        Course
            ├── course_id: str
            ├── name: str
            ├── credit: int
            └── __str__()
        Grade
            ├── student: Student
            ├── course: Course
            ├── score: float
            └── __init__(student, course, score)

项目总结
    本项目充分体现了 OOP 的核心特性：
        1. 封装：每个类都封装了自己的数据和方法，如Student类封装了学生的基本信息和成绩计算方法
        2. 继承：虽然本项目没有直接使用继承，但可以通过继承来扩展不同类型的学生（如本科生、研究生）
        3. 多态：不同学生对象可以对相同的方法（如calculate_gpa()）做出不同的响应
        4. 抽象：通过抽象出Course、Student、Grade等类，隐藏了复杂的实现细节

    项目还体现了以下设计原则：
        - 单一职责原则：每个类都有明确的职责
        - 开闭原则：可以方便地添加新的课程、学生或功能
        - 依赖倒置原则：高层模块（School）不依赖底层模块的具体实现

补充：
    父类的私有成员是否可以被子类继承？
        1. 严格来说：Python 中父类以 __双下划线 开头的私有成员，子类不能直接继承访问。
            Python 私有成员 以双下划线 __ 开头的属性 / 方法：
            Python 会做名称改写：把 __money 改成 _类名__money，外部和子类都不能直接访问。
        2. 子类无法直接继承访问
            __money 被改写成 _Father__money，子类作用域里没有这个名字，不能直接继承调用。

        3. 关键点：不是完全没继承
            私有成员实际内存里是存在的，只是语法上屏蔽了访问。可以强行间接访问（不推荐）：
                s = Son()
                print(s._Father__money)  # 能拿到，违反封装规范

        4. 单下划线 _xxx 受保护成员
            - 语法不强制限制
            - 约定俗成：子类可以继承、可以访问，视为保护成员

        区分：
            1. __xxx 双下划线私有：
                子类不能直接继承访问，Python 名称改写屏蔽，真正意义私有。
            2. _xxx 单下划线保护：
                子类可以继承、可以访问，只是编程约定不外部乱用。

        补充的补充（面向对象理论）
            Java/C++ 里 private 私有成员彻底不被子类继承；
            Python 是语法屏蔽、实际存在，只是不让你直接用，和静态语言略有区别。
